## 口径与边界

- Excel 保留模板五列，不增加说明列；指标名称基于资源原名，去除“平均值”和“实际值”；聚合类型仍为“平均值”，资源键及实际值/设定值的数据口径保持不变。“平均值”指各点位在统计区间内的均值，不表示多个点位之间求平均。
- 排除罩式炉 DL～EQ（含二级技术方案）、检化验 G～H、AZ～BA、BC～BD、BF～BG。A～E 是日期、卷号、厚度等基础信息，不作为数采工艺指标。F 列按 F4 的“铁损仪曲线平均铁损”纳入在线铁损。
- “相关资源，口径待确认”表示 Excel 已收录名称真实的相关点位，但不足以证明严格满足 HIB 原栏目。尤其不能把出口管温度等同水温，把 kN 等同 MPa 或 N/mm²，把实际值等同设定值。未自行计算单位换算或引入模板外公式。
- 原表仅在罩式炉 DM5 明确提到二级；明确标为 L1 的风机开度资源保留。其余炉温优先使用实际值，不把设定值、偏差值混作实际温度。
- 所有资源按“机组代码 + unique_key”去重，不跨机组复用；资源重复行号在明细中完整保留。重复键采用最后一条的中文名称。
- 机组中文名称沿用同目录点位收集表中的 CP1 / DCL1 名称及现有系统中的 FCL1 名称。资源表只提供代码，正式导入前需与目标环境机组字典核对。
- 缺失资源不虚构检测参数、不插入不可导入的占位行；下表列出缺口。若需严格覆盖全部原栏目，须补充缺失资源并确认口径差异。
