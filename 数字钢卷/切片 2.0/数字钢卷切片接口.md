# 数字钢卷切片接口

## 接口路径

POST /api/quality/piece/output

## 入参

| 参数                 | 类型     | 必填  | 说明          |
| ------------------ | ------ | --- | ----------- |
| unitCode           | String | 是   | 机组代码        |
| outMatNo           | String | 是   | 出口物料号       |
| outMatRepeatProdNo | String | 是   | 出口物料重复生产次数号 |
| cellCode           | String | 是   | 加工单元代码      |

## 数字钢卷切片流程

#### 变量命名与入参

所有长度单位统一为米，位置均为到各自带头的距离。

| 变量                        | 含义                      |
| ------------------------- | ----------------------- |
| `outMatLength`            | 成品卷长度                   |
| `outMatPos`               | 成品卷位置，到成品带头的距离          |
| `outMatHead`              | 按成品方向定义的切头量，对应在线方向的切尾量  |
| `outMatTail`              | 按成品方向定义的切尾量，对应在线方向的切头量  |
| `coilLength`              | 当前工艺段在线卷剪切前的完整长度        |
| `coilPos`                 | 在线卷位置，到在线带头的距离          |
| `coilHead`                | 按在线运行方向记录的切头量           |
| `coilTail`                | 按在线运行方向记录的切尾量           |
| `coilSlice`               | 按在线运行方向记录的分切量           |
| `lengthScale`             | 补齐剪切量后的完整长度转实际在线长度的缩放系数 |
| `outMatStart`、`outMatEnd` | 切片在目标成品卷中的起点、终点         |
| `coilStart`、`coilEnd`     | 换算区间在对应入口在线卷中的起点、终点     |

### 基础数据初始化

1. qm_biz_digital_factory 表查询机组对应的数字钢卷切片存储的时序数据库、表名和精度
2. qm_biz_parameter 表查询机组对应的数字钢卷工艺参数的名字、类型、唯一键和存储的时序表和时序库
3. qm_mat_cells_blood 查询加工单元对应的入口出口物料流转情况，需要查询出包含完整分卷/并卷物料流转情况的记录

### 数字钢卷切片长度生成

在加工单元对应的入口出口物料流转情况中，取对应出口物料的长度，根据 qm_biz_digital_factory 配置的精度，对出口物料长度进行切片划分，每个切片有其 piece_no，对应着出口物料的一段长度

### 剪切数据准备

每个切片都对应一段成品卷长度。将成品卷补齐卷取机的头尾剪切量，按卷取方向反转头尾，再将包含剪切量的完整长度整体缩放到实际在线卷长度，即可得到对应的在线长度区间，从而关联跟踪数据中的工艺参数和表检仪缺陷。剪切量本身存在误差，必须参与整体缩放。

表数据使用说明：

1. qm_mat_cells_blood 查询结果的各行 mat_type 值都一样，取第一条的 mat_type 值即可。
2. qm_dc_shear_log 查询结果的剪切实绩中，shear_type 的第三位（shear_type[2]）代表剪切类型，1 代表切头，5 代表分切，9 代表切尾；shear_device_code 以 tr 开头表示卷取机，以 por 开头表示开卷机。
3. qm_dc_coiler_log 中的开卷/卷取方式的第一位（uncoiler_method/coiler_method[0]）为 1 代表上，第一位为 9 代表下。

#### 正常卷产出

1. mat_type = 0 时，qm_mat_cells_blood 查询结果只有一条数据。
2. qm_dc_shear_log 表查询该入口物料的剪切实绩
3. 入口物料
4. 计算该条数据的入口物料的在卷取机上的切头量、切尾量，所有卷取机上切头的 shear_length 之和为切头量，所有卷取机上切尾的 shear_length 之和为切尾量

#### 并卷产出

1. mat_type = 1 时，qm_mat_cells_blood 查询结果有多条入口物料不一样，出口物料一样的数据，out_mat_sequence_no 标明了多个入口物料的焊接顺序
2. qm_dc_shear_log 表查询多条入口物料的剪切实绩
3. 计算每条入口物料在卷取机上的切头量、切尾量，所有卷取机上切头的 shear_length 之和为切头量，所有卷取机上切尾的 shear_length 之和为切尾量

#### 分卷产出

1. mat_type = 2 时，qm_mat_cells_blood 查询结果有多条入口物料一样，出口物料不一样的数据，out_mat_sequence_no 标明了多个出口卷物料的切分顺序
2. qm_dc_shear_log 表查询入口物料的剪切实绩
3. 根据入口物料在卷取机上切头、切尾、分切量，所有卷取机上切头的 shear_length 之和为切头量，所有卷取机上切尾的 shear_length 之和为切尾量，对于分切，用 shear_no 区分每一次分切，卷取机上的 一次 shear_no 内的所有 shear_length 之和为分切量
4. 每个出口物料都有自己的切头量和切尾量，入口物料的切头量被算作是第一个出口物料的切头量，入口物料的每一次分切量被算作是下一个出口物料的切头量，入口物料的切尾量被算作是最后一个出口物料的切尾量。qm_dc_shear_log 记录的分切次数和实际分切次数不一定一致，qm_dc_shear_log 多的分切次数不用管，少的分切次数，后面的出口物料的切头量都按 0 算

### 在线卷长度数据准备

### 成品卷长度转在线卷长度

在线卷经过切头、切尾，再因卷取发生头尾反转，得到成品卷。逆变换时，先给成品卷补齐头尾剪切量，再反转方向，最后整体缩放到实际在线卷长度。剪切量本身也是长度误差的来源，因此成品长度、剪切量和累计偏移都必须参与同一次缩放。

#### 变量命名与入参

所有长度单位统一为米，位置均为到各自带头的距离。

| 变量                        | 含义                      |
| ------------------------- | ----------------------- |
| `outMatLength`            | 成品卷长度                   |
| `outMatPos`               | 成品卷位置，到成品带头的距离          |
| `outMatHead`              | 按成品方向定义的切头量，对应在线方向的切尾量  |
| `outMatTail`              | 按成品方向定义的切尾量，对应在线方向的切头量  |
| `coilLength`              | 当前工艺段在线卷剪切前的完整长度        |
| `coilPos`                 | 在线卷位置，到在线带头的距离          |
| `coilHead`                | 按在线运行方向记录的切头量           |
| `coilTail`                | 按在线运行方向记录的切尾量           |
| `coilSlice`               | 按在线运行方向记录的分切量           |
| `lengthScale`             | 补齐剪切量后的完整长度转实际在线长度的缩放系数 |
| `outMatStart`、`outMatEnd` | 切片在目标成品卷中的起点、终点         |
| `coilStart`、`coilEnd`     | 换算区间在对应入口在线卷中的起点、终点     |

上卷取、下卷取均反转头尾，因此同一份剪切记录按两个方向命名时：

```text
outMatHead = coilTail
outMatTail = coilHead
```

以上等式表示剪切记录在两个方向上的对应关系。剪切量尚未经过长度对齐，不能直接把记录值当作实际在线坐标中的边界距离；映射到实际在线坐标时，它们同样要乘 `lengthScale`。

```text
convertRange(context, outMatStart, outMatEnd, coilLengths)
    -> 多个 {入口物料标识, coilStart, coilEnd}
```

- `context`：目标出口卷、完整分卷/并卷关系、成品长度及前文准备的剪切量。
- `outMatStart`、`outMatEnd`：当前切片在目标成品卷上的长度范围。
- `coilLengths`：当前工艺段各入口物料的实际在线完整长度，以入口物料号和重复生产次数号共同索引，取出的值为 `coilLength`，与该段 `head_length` 坐标口径一致。

实际在线长度在读取各工艺段时确定，因此每个段单独传入在线长度并调用换算，不提前固定缩放系数。

#### 正常卷

成品卷补齐剪切量后，成品位置 `outMatPos` 到补齐后带头的距离为 `outMatPos + outMatHead`，完整长度为 `outMatLength + outMatHead + outMatTail`。将该距离整体缩放到在线长度，再反转方向：

```text
lengthScale = coilLength / (outMatLength + outMatHead + outMatTail)

coilPos = coilLength - (outMatPos + outMatHead) * lengthScale
```

即：

```text
coilPos = coilLength
    - (outMatPos + outMatHead) * coilLength
    / (outMatLength + outMatHead + outMatTail)
```

使用在线方向的剪切量表示，等价为：

```text
lengthScale = coilLength / (outMatLength + coilHead + coilTail)
coilPos = (coilHead + outMatLength - outMatPos) * lengthScale
```

端点对应关系为：

```text
outMatPos = 0
    -> coilPos = coilLength - outMatHead * lengthScale
               = coilLength - coilTail * lengthScale

outMatPos = outMatLength
    -> coilPos = outMatTail * lengthScale
               = coilHead * lengthScale
```

成品带头对应在线切尾后的保留段尾端，成品带尾对应在线切头后的保留段头端。两端被切掉的长度均按 `lengthScale` 对齐，而非固定保留剪切记录的原始数值。

切片换算时，反转后按在线坐标从小到大返回：

```text
coilStart = coilLength - (outMatEnd + outMatHead) * lengthScale
coilEnd = coilLength - (outMatStart + outMatHead) * lengthScale
```

例如 `outMatLength = 100`、`outMatHead = 3`、`outMatTail = 5`、`coilLength = 110`，则 `lengthScale = 110 / 108`。成品切片 `[0,10]` 对应在线区间约 `[96.759259,106.944444]`；整个成品 `[0,100]` 对应约 `[5.092593,106.944444]`，两侧剪切量也都乘了相同比例。

#### 分卷

全部子卷按 `out_mat_sequence_no` 数值升序排列，即在线运行方向上的切分顺序。`coilLength` 为同一入口的实际在线完整长度；第 j 个子卷使用 `outMatLength[j]`、`outMatHead[j]`、`outMatTail[j]`。

先按在线方向分配剪切记录：首卷承接入口 `coilHead`，后续卷承接前一次 `coilSlice`，末卷承接入口 `coilTail`；分切量只计入下一卷一次。再根据方向转换得到各子卷的 `outMatHead[j]`、`outMatTail[j]`：

```text
outMatHead[j] = coilTail[j]
outMatTail[j] = coilHead[j]
```

这里 `coilHead[j]`、`coilTail[j]` 为分配给第 j 个子卷的在线方向剪切记录。每个子卷只在自己的区间内反转头尾，不能将全部子卷作为一个成品整体反转。

全部子卷补齐剪切量后的长度共用一个缩放系数：

```text
restoredLength[j] = outMatLength[j] + outMatHead[j] + outMatTail[j]
lengthScale = coilLength / sum(restoredLength[j])
restoredStart[j] = sum(restoredLength[q], q < j)
```

`restoredStart[j]` 为第 j 个子卷补齐剪切量后，沿在线方向累计的未缩放起点。当前目标子卷内的成品位置换算为：

```text
coilPos = (restoredStart[j] + restoredLength[j]
    - outMatPos - outMatHead[j]) * lengthScale

coilStart = (restoredStart[j] + restoredLength[j]
    - outMatEnd - outMatHead[j]) * lengthScale
coilEnd = (restoredStart[j] + restoredLength[j]
    - outMatStart - outMatHead[j]) * lengthScale
```

前序子卷长度、剪切量以及当前卷的偏移都在括号内，统一参与缩放。该方式采用同一入口统一比例的假设；有可靠的实际分切位置时，优先按实测边界分别对齐。

#### 并卷

各入口按 `out_mat_sequence_no` 数值升序排列，即在线运行方向上的焊接顺序。`outMatLength` 为最终成品总长，第 i 个入口的实际在线完整长度为 `coilLength[i]`，剪切记录为 `coilHead[i]`、`coilTail[i]`。

采用整次并卷统一比例，将成品总长补齐所有入口剪切量后，与全部入口在线总长对齐：

```text
outMatHead[i] = coilTail[i]
outMatTail[i] = coilHead[i]

lengthScale = sum(coilLength[i])
    / (outMatLength + sum(outMatHead[i] + outMatTail[i]))

outMatPartLength[i] = coilLength[i] / lengthScale
    - outMatHead[i] - outMatTail[i]
outMatPartStart[i] = outMatLength - sum(outMatPartLength[q], q <= i)
outMatPartEnd[i] = outMatPartStart[i] + outMatPartLength[i]
```

`outMatPartLength[i]` 为第 i 个入口贡献的成品长度，总和等于 `outMatLength`；`outMatPartStart[i]`、`outMatPartEnd[i]` 为该贡献段在最终成品中的起点、终点。并卷整体反转头尾，因此成品从头到尾的入口顺序与焊接顺序相反。

切片与各入口的成品贡献区间求交：

```text
outMatOverlapStart = max(outMatStart, outMatPartStart[i])
outMatOverlapEnd = min(outMatEnd, outMatPartEnd[i])
```

若 `outMatOverlapStart < outMatOverlapEnd`，先减去贡献段起点，得到入口贡献段内的位置，再按正常卷公式转换到该入口的在线坐标：

```text
coilPos = coilLength[i]
    - (outMatPos - outMatPartStart[i] + outMatHead[i]) * lengthScale

coilStart = coilLength[i]
    - (outMatOverlapEnd - outMatPartStart[i] + outMatHead[i]) * lengthScale
coilEnd = coilLength[i]
    - (outMatOverlapStart - outMatPartStart[i] + outMatHead[i]) * lengthScale
```

跨焊缝时返回多个入口区间，按成品坐标升序排列；各入口在线坐标独立从 0 起算。计算需要当前段全部入口的 `coilLength[i]`。统一比例保证总长闭合，但焊缝位置仍是比例推算结果；有可靠的成品焊缝位置时，优先按实测边界分别对齐。

#### 调用要点

数据准备阶段保留完整血缘、成品长度和原始剪切记录；读取每个工艺段时，传入该段各入口实际在线完整长度，计算 `lengthScale`，再获取在线区间并查询该段工艺参数。必须将剪切量纳入完整长度一起缩放，不能先从实际在线长度中扣除未经对齐的剪切量，只对保留段缩放。

要求成品长度、实际在线长度和缩放分母为正，剪切量非负；并卷各 `outMatPartLength[i]` 必须为正。切片满足 `0 <= outMatStart < outMatEnd <= outMatLength`，分卷时使用目标子卷的 `outMatLength[j]`。切片越界、实际在线长度缺失或长度不满足上述条件时报错。

上述公式中的区间表示几何边界。成品切片按左闭右开查询，最后一片包含成品终点；反向映射后相应为左开右闭，仅映射自包含成品总长的交集段才包含在线下界。并卷各入口的成品贡献区间也按同一规则划分，求交时保留端点开闭属性，避免焊缝重复归属。最后切片跨焊缝时，不能把所有返回段都改成双闭。正常卷、分卷的在线区间长度，以及并卷跨焊缝返回的区间长度之和，均应等于 `(outMatEnd - outMatStart) * lengthScale`。
