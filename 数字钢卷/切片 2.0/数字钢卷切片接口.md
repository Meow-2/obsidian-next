# 数字钢卷切片接口

## 接口路径

POST /api/quality/piece/output

## 入参

| 参数                 | 类型     | 必填  | 说明          |
| ------------------ | ------ | --- | ----------- |
| unitCode           | String | 是   | 机组代码        |
| outMatNo           | String | 是   | 出口物料号       |
| outMatRepeatProdNo | String | 是   | 出口物料重复生产次数号 |
| cellCode           | String | 是   | 加工单元代码      |

## 数字钢卷切片流程

### 基础数据初始化

1. qm_biz_digital_factory 表查询机组对应的数字钢卷切片存储的时序数据库、表名和精度
2. qm_biz_parameter 表查询机组对应的数字钢卷工艺参数的名字、类型、唯一键和存储的时序表和时序库
3. qm_mat_cells_blood 查询加工单元对应的入口出口物料流转情况，需要查询出包含完整分卷/并卷物料流转情况的记录

### 数字钢卷切片长度生成

在加工单元对应的入口出口物料流转情况中，取对应出口物料的长度，根据 qm_biz_digital_factory 配置的精度，对出口物料长度进行切片划分，每个切片有其 piece_no，对应着出口物料的一段长度

### 成品卷长度转在线卷长度前的数据准备

每个切片都对应一段成品卷长度。将成品卷坐标按卷取方向反转，再与在线卷扣除卷取机切头、切尾后的保留段按比例对齐，即可得到对应的在线长度区间，从而关联跟踪数据中的工艺参数和表检仪缺陷。

表数据使用说明：

1. qm_mat_cells_blood 查询结果的各行 mat_type 值都一样，取第一条的 mat_type 值即可。
2. qm_dc_shear_log 查询结果的剪切实绩中，shear_type 的第三位（shear_type[2]）代表剪切类型，1 代表切头，5 代表分切，9 代表切尾；shear_device_code 以 tr 开头表示卷取机，以 por 开头表示开卷机。
3. qm_dc_coiler_log 中的开卷/卷取方式的第一位（uncoiler_method/coiler_method[0]）为 1 代表上，第一位为 9 代表下。

#### 正常卷产出

 mat_type = 0 时，qm_mat_cells_blood 查询结果只有一条数据。

##### 卷取情况

1. qm_dc_coiler_log 表查询该入口物料的卷取方式

##### 卷取机头尾剪切量

1. qm_dc_shear_log 表查询该入口物料的剪切实绩
2. 计算该条数据的入口物料的在卷取机上的切头量、切尾量，所有卷取机上切头的 shear_length 之和为切头量，所有卷取机上切尾的 shear_length 之和为切尾量

#### 并卷产出

mat_type = 1 时，qm_mat_cells_blood 查询结果有多条入口物料不一样，出口物料一样的数据，out_mat_sequence_no 标明了多个入口物料的焊接顺序

##### 卷取情况

1. qm_dc_coiler_log 表查询多条入口物料的卷取方式

##### 卷取机头尾剪切量

1. qm_dc_shear_log 表查询多条入口物料的剪切实绩
2. 计算每条入口物料在卷取机上的切头量、切尾量，所有卷取机上切头的 shear_length 之和为切头量，所有卷取机上切尾的 shear_length 之和为切尾量

#### 分卷产出

mat_type = 2 时，qm_mat_cells_blood 查询结果有多条入口物料一样，出口物料不一样的数据，out_mat_sequence_no 标明了多个出口卷物料的切分顺序

##### 卷取情况

1. qm_dc_coiler_log 表查询入口物料的卷取方式

##### 卷取机头尾剪切量

1. qm_dc_shear_log 表查询入口物料的剪切实绩
2. 根据入口物料在卷取机上切头、切尾、分切量，所有卷取机上切头的 shear_length 之和为切头量，所有卷取机上切尾的 shear_length 之和为切尾量，对于分切，用 shear_no 区分每一次分切，卷取机上的 一次 shear_no 内的所有 shear_length 之和为分切量
3. 每个出口物料都有自己的切头量和切尾量，入口物料的切头量被算作是第一个出口物料的切头量，入口物料的每一次分切量被算作是下一个出口物料的切头量，入口物料的切尾量被算作是最后一个出口物料的切尾量。qm_dc_shear_log 记录的分切次数和实际分切次数不一定一致，qm_dc_shear_log 多的分切次数不用管，少的分切次数，后面的出口物料的切头量都按 0 算

### 成品卷长度转在线卷长度

正向过程是：在线卷先切头、切尾，保留段再经过卷取造成的头尾反转，得到成品卷。理论上，在线保留段长度等于成品卷长度；实际测量存在误差，需要将这两个长度按比例对齐。

成品卷转在线卷执行逆变换：先反转头尾，再将成品长度缩放到在线保留段长度，最后加上该保留段在在线卷中的起点偏移。所有长度单位统一为米；上卷取、下卷取均反转头尾。

#### 变量命名与入参

变量使用 `finished` 表示成品卷坐标，使用 `online` 表示在线卷坐标；多卷场景通过数组下标区分物料。

| 变量 | 含义 |
| --- | --- |
| `finishedCoilLength` | 成品卷总长 |
| `onlineCoilLength` | 当前工艺段在线卷剪切前的完整总长 |
| `onlineHeadCutLength` | 在线带头侧切头量 |
| `onlineTailCutLength` | 在线带尾侧切尾量 |
| `onlineRetainedLength` | 在线卷扣除剪切量后的保留长度 |
| `onlineRetainedStart`、`onlineRetainedEnd` | 在线保留段在在线卷坐标中的起点、终点 |
| `finishedToOnlineScale` | 成品长度转在线保留长度的缩放系数，即在线保留长度 / 成品长度 |
| `finishedCoilPosition`、`onlineCoilPosition` | 同一材料位置在成品卷、在线卷中的长度坐标 |
| `finishedSliceStart`、`finishedSliceEnd` | 切片在目标成品卷中的起点、终点 |
| `onlineRangeStart`、`onlineRangeEnd` | 映射区间在对应入口在线卷中的起点、终点 |

以下 `onlineHeadCutLength`、`onlineTailCutLength` 均指已换算到当前工艺段在线坐标口径的剪切长度，不随成品保留段一起缩放；若剪切设备与当前段计长口径不同，须先完成剪切长度的口径换算，不能仅凭单位相同直接使用。

```text
convertRange(context, finishedSliceStart, finishedSliceEnd, onlineCoilLengths)
    -> 多个 {入口物料标识, onlineRangeStart, onlineRangeEnd}
```

- `context`：目标出口卷、完整分卷/并卷关系、成品长度及前文准备的剪切量。
- `finishedSliceStart`、`finishedSliceEnd`：当前切片在目标成品卷上的长度范围，从成品带头起算。
- `onlineCoilLengths`：当前工艺段各入口物料的完整在线总长，以入口物料号和重复生产次数号共同索引，取出的值为 `onlineCoilLength`，坐标口径与该段跟踪数据的 `head_length` 一致。

在线总长在读取各工艺段时确定，因此每个段单独传入在线长度并调用换算，不提前固定缩放系数。在线坐标从最先通过设备的带头起算，切头、切尾均按在线运行方向定义。

#### 正常卷

先确定在线保留段：

```text
onlineRetainedStart = onlineHeadCutLength
onlineRetainedEnd = onlineCoilLength - onlineTailCutLength
onlineRetainedLength = onlineRetainedEnd - onlineRetainedStart
```

成品带头对应 `onlineRetainedEnd`，成品带尾对应 `onlineRetainedStart`。对在线保留段中的位置 `onlineCoilPosition`，正向过程先扣除切头偏移，将在线保留长度对齐到成品长度，再反转头尾：

```text
finishedCoilPosition = finishedCoilLength
    - (onlineCoilPosition - onlineRetainedStart) * finishedCoilLength / onlineRetainedLength
```

解出 `onlineCoilPosition`，得到逆变换：

```text
finishedToOnlineScale = onlineRetainedLength / finishedCoilLength

onlineCoilPosition = onlineRetainedStart
    + (finishedCoilLength - finishedCoilPosition) * finishedToOnlineScale
// 等价写法：
onlineCoilPosition = onlineRetainedEnd - finishedCoilPosition * finishedToOnlineScale

onlineRangeStart = onlineRetainedEnd - finishedSliceEnd * finishedToOnlineScale
onlineRangeEnd = onlineRetainedEnd - finishedSliceStart * finishedToOnlineScale
```

长度关系为：

```text
onlineCoilLength = onlineHeadCutLength
    + finishedCoilLength * finishedToOnlineScale + onlineTailCutLength
```

端点满足：`finishedCoilPosition = 0` 映射到 `onlineRetainedEnd`；`finishedCoilPosition = finishedCoilLength` 映射到 `onlineRetainedStart`。理论等长时 `finishedToOnlineScale = 1`；实际有误差时，只缩放成品对应的保留段，在线切头和切尾长度保持不变。

例如 `finishedCoilLength = 100`、`onlineCoilLength = 110`、`onlineHeadCutLength = 5`、`onlineTailCutLength = 3`，则 `onlineRetainedLength = 102`、`finishedToOnlineScale = 1.02`。成品切片 `[0,10]` 对应在线区间 `[96.8,107]`，在线区间长 10.2 米；整个成品 `[0,100]` 恰好映射到在线保留段 `[5,107]`。

#### 分卷

全部子卷按 `out_mat_sequence_no` 数值升序排列，即在线运行方向上的切分顺序。第 j 卷成品长为 `finishedCoilLength[j]`，分配到该卷的在线切头、切尾量为 `onlineHeadCutLength[j]`、`onlineTailCutLength[j]`，沿用前文规则：首卷承接入口切头，后续卷承接前一次分切，末卷承接入口切尾。`onlineCoilLength` 为全部子卷共用的入口在线总长。

只有各子卷成品长度和入口在线总长，无法分别确定每个子卷在线保留段的实际长度；这里采用同一入口的全部子卷共用一个缩放系数的假设，将扣除所有剪切量后的在线长度按各子卷成品长度比例分配：

```text
onlineTotalCutLength = sum(onlineHeadCutLength[j] + onlineTailCutLength[j])
finishedCoilTotalLength = sum(finishedCoilLength[j])
onlineRetainedTotalLength = onlineCoilLength - onlineTotalCutLength
finishedToOnlineScale = onlineRetainedTotalLength / finishedCoilTotalLength

onlineRetainedLength[j] = finishedCoilLength[j] * finishedToOnlineScale
onlineRetainedStart[j] = sum(
    onlineHeadCutLength[q] + onlineRetainedLength[q] + onlineTailCutLength[q], q < j
) + onlineHeadCutLength[j]
onlineRetainedEnd[j] = onlineRetainedStart[j] + onlineRetainedLength[j]

onlineCoilPosition = onlineRetainedEnd[j] - finishedCoilPosition * finishedToOnlineScale
onlineRangeStart = onlineRetainedEnd[j] - finishedSliceEnd * finishedToOnlineScale
onlineRangeEnd = onlineRetainedEnd[j] - finishedSliceStart * finishedToOnlineScale
```

`finishedCoilPosition`、`finishedSliceStart`、`finishedSliceEnd` 均为当前目标子卷内的成品坐标。全部子卷共用同一个入口在线坐标系，每个子卷在自己的保留段内反转头尾。累计前序卷偏移时，成品长度乘 `finishedToOnlineScale`，剪切量直接相加；分切量只计入下一卷的 `onlineHeadCutLength[j]`，避免重复累计。最后一个子卷保留段的尾端应等于 `onlineCoilLength` 减去入口切尾量。

例如两卷 `finishedCoilLength[1] = 40`、`finishedCoilLength[2] = 60`，`onlineCoilLength = 112`，入口切头 5、分切量 2、入口切尾 3，则 `onlineTotalCutLength = 10`、`finishedToOnlineScale = 1.02`：

```text
onlineRetainedLength[1] = 40.8
onlineRetainedLength[2] = 61.2
onlineRetainedStart[1] = 5
onlineRetainedStart[2] = 47.8
onlineRetainedEnd[2] = 109
```

第二卷成品切片 `[0,10]` 对应在线区间 `[98.8,109]`；最后保留段尾端 109 = 112 - 3。

#### 并卷

各入口按 `out_mat_sequence_no` 数值升序排列，即在线运行方向上的焊接顺序。`finishedCoilLength` 为最终成品总长，第 i 个入口的当前段在线总长为 `onlineCoilLength[i]`，在线切头、切尾量为 `onlineHeadCutLength[i]`、`onlineTailCutLength[i]`。

先从每个入口在线总长中扣除其剪切量，再将全部在线保留长度与成品总长对齐。这里采用整次并卷共用一个缩放系数的假设，据此确定各入口贡献的成品长度及焊缝位置：

```text
onlineRetainedStart[i] = onlineHeadCutLength[i]
onlineRetainedEnd[i] = onlineCoilLength[i] - onlineTailCutLength[i]
onlineRetainedLength[i] = onlineRetainedEnd[i] - onlineRetainedStart[i]
onlineRetainedTotalLength = sum(onlineRetainedLength[i])
finishedToOnlineScale = onlineRetainedTotalLength / finishedCoilLength

finishedContributionLength[i] = onlineRetainedLength[i] / finishedToOnlineScale
finishedContributionStart[i] = finishedCoilLength
    - sum(finishedContributionLength[q], q <= i)
finishedContributionEnd[i] = finishedContributionStart[i] + finishedContributionLength[i]
```

`finishedContributionLength[i]` 为第 i 个入口贡献到成品中的长度，其总和等于 `finishedCoilLength`；`finishedContributionStart[i]`、`finishedContributionEnd[i]` 为该贡献段在最终成品卷中的起点、终点。

第 i 个入口覆盖的成品区间为 `[finishedContributionStart[i], finishedContributionEnd[i]]`，对应其自身在线保留段 `[onlineRetainedStart[i], onlineRetainedEnd[i]]`。切片与该成品区间求交：

```text
finishedOverlapStart = max(finishedSliceStart, finishedContributionStart[i])
finishedOverlapEnd = min(finishedSliceEnd, finishedContributionEnd[i])
```

`finishedOverlapStart`、`finishedOverlapEnd` 仍为最终成品卷的全局坐标。若 `finishedOverlapStart < finishedOverlapEnd`，返回该入口对应的在线区间：

```text
onlineCoilPosition = onlineRetainedEnd[i]
    - (finishedCoilPosition - finishedContributionStart[i]) * finishedToOnlineScale

onlineRangeStart = onlineRetainedEnd[i]
    - (finishedOverlapEnd - finishedContributionStart[i]) * finishedToOnlineScale
onlineRangeEnd = onlineRetainedEnd[i]
    - (finishedOverlapStart - finishedContributionStart[i]) * finishedToOnlineScale
```

成品贡献段的起点 `finishedContributionStart[i]` 映射到 `onlineRetainedEnd[i]`，终点 `finishedContributionEnd[i]` 映射到 `onlineRetainedStart[i]`。跨焊缝时返回多个入口区间，按成品坐标升序排列。计算需要当前段全部入口的 `onlineCoilLength[i]`，不能仅传入一个入口长度；成品从头到尾对应的入口顺序与焊接顺序相反。

例如按顺序焊接入口 A、B，`finishedCoilLength = 100`，各入口数据为：

| 变量 | 入口 A | 入口 B |
| --- | --- | --- |
| `onlineCoilLength[i]` | 45.8 | 65.2 |
| `onlineHeadCutLength[i]` | 2 | 1 |
| `onlineTailCutLength[i]` | 3 | 3 |
| `onlineRetainedLength[i]` | 40.8 | 61.2 |
| `finishedContributionLength[i]` | 40 | 60 |
| `finishedContributionStart[i]` | 60 | 0 |
| `finishedContributionEnd[i]` | 100 | 60 |

此时 `finishedToOnlineScale = 1.02`。成品区间 `[0,60]` 来自 B，`[60,100]` 来自 A；跨焊缝切片 `[55,65]` 对应 B 的在线区间 `[1,6.1]` 和 A 的在线区间 `[37.7,42.8]`，两段合计 10.2 米。

#### 调用要点

数据准备阶段只保留完整血缘、成品长度和剪切量；读取每个工艺段时，传入该段各入口完整在线总长，计算保留长度及 `finishedToOnlineScale`，再获取在线区间并查询该段工艺参数。各入口在线坐标独立从 0 起算。剪切实绩须与该段在线坐标使用同一长度口径。

正常卷的缩放系数为 `(onlineCoilLength - onlineHeadCutLength - onlineTailCutLength) / finishedCoilLength`；分卷、并卷均先扣除剪切量，再对保留段进行比例对齐。已换算到当前段在线口径的剪切量不乘 `finishedToOnlineScale`，不能再用 `onlineCoilLength / (finishedCoilLength + onlineHeadCutLength + onlineTailCutLength)` 将其一起缩放。分卷、并卷的统一比例是缺少各保留段独立对应长度时采用的假设：它保证总长和端点闭合，但不能保证实际分切点或焊缝位置完全准确。若有可靠的子卷在线边界或成品焊缝位置，应优先使用这些实测边界分别对齐。

要求成品长度、各入口在线总长、扣除剪切量后的在线保留长度及缩放分母为正，剪切量非负，切片满足 `0 <= finishedSliceStart < finishedSliceEnd <= finishedCoilLength`。分卷时 `finishedCoilLength` 取目标子卷的 `finishedCoilLength[j]`。切片越界、实际在线总长缺失或剪切量不满足上述条件时应报错。实际保留长度与成品长度的误差通过 `finishedToOnlineScale` 对齐，不要求二者相等。

上述公式中的区间表示几何边界。查询时成品切片统一左闭右开，最后一片包含 `finishedCoilLength`；反向映射后相应为左开右闭，仅映射自包含 `finishedCoilLength` 的交集段才包含在线下界。并卷各入口的成品覆盖区间也按左闭右开划分，包含 `finishedCoilLength` 的区间包含该终点；切片与入口覆盖区间求交时保留端点开闭属性，再反向映射。例如焊接顺序为 A、B 时，成品顺序为 B、A，焊缝坐标归 A 对应区间；最后切片即使跨焊缝，也只有映射到 A 并包含 `finishedCoilLength` 的那一段包含在线下界，不能把所有返回段都改成双闭。分卷中 `finishedCoilLength` 指当前目标子卷的成品长度。正常卷、分卷的映射区间长度应为 `(finishedSliceEnd - finishedSliceStart) * finishedToOnlineScale`；并卷跨焊缝返回的多个区间长度之和也应等于该值。
