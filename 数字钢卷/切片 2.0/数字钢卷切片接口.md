# 数字钢卷切片接口

## 接口路径

POST /api/quality/piece/output

## 入参

| 参数                 | 类型     | 必填  | 说明          |
| ------------------ | ------ | --- | ----------- |
| unitCode           | String | 是   | 机组代码        |
| outMatNo           | String | 是   | 出口物料号       |
| outMatRepeatProdNo | String | 是   | 出口物料重复生产次数号 |
| cellCode           | String | 是   | 加工单元代码      |

## 数字钢卷切片流程

### 基础数据初始化

1. qm_biz_digital_factory 表查询机组对应的数字钢卷切片存储的时序数据库、表名和精度
2. qm_biz_parameter 表查询机组对应的数字钢卷工艺参数的名字、类型、唯一键和存储的时序表和时序库
3. qm_mat_cells_blood 查询加工单元对应的入口出口物料流转情况，需要查询出包含完整分卷/并卷物料流转情况的记录

### 数字钢卷切片长度生成

在加工单元对应的入口出口物料流转情况中，取对应出口物料的长度，根据 qm_biz_digital_factory 配置的精度，对出口物料长度进行切片划分，每个切片有其 piece_no，对应着出口物料的一段长度

### 成品卷长度转在线卷长度前的数据准备

每个切片都对应一段成品卷长度。而成品卷的长度补上**卷取机的头尾剪切量**和**卷取造成的头尾变换**后可以对应到在线卷的长度，从而和跟踪数据的工艺参数和表检仪式缺陷关联上。

表数据使用说明：

1. qm_mat_cells_blood 查询结果的各行 mat_type 值都一样，取第一条的 mat_type 值即可。
2. qm_dc_shear_log 查询结果的剪切实绩中，shear_type 的第三位（shear_type[2]）代表剪切类型，1 代表切头，5 代表分切，9 代表切尾；shear_device_code 以 tr 开头表示卷取机，以 por 开头表示开卷机。
3. qm_dc_coiler_log 中的开卷/卷取方式的第一位（uncoiler_method/coiler_method[0]）为 1 代表上，第一位为 9 代表下。

#### 正常卷产出

 mat_type = 0 时，qm_mat_cells_blood 查询结果只有一条数据。

##### 卷取情况

1. qm_dc_coiler_log 表查询该入口物料的卷取方式

##### 卷取机头尾剪切量

1. qm_dc_shear_log 表查询该入口物料的剪切实绩
2. 计算该条数据的入口物料的在卷取机上的切头量、切尾量，所有卷取机上切头的 shear_length 之和为切头量，所有卷取机上切尾的 shear_length 之和为切头量

#### 并卷产出

mat_type = 1 时，qm_mat_cells_blood 查询结果有多条入口物料不一样，出口物料一样的数据

##### 卷取情况

1. qm_dc_coiler_log 表查询多条入口物料的卷取方式

##### 卷取机头尾剪切量

1. qm_dc_shear_log 表查询多条入口物料的剪切实绩
2. 计算每条入口物料在卷取机上的切头量、切尾量，所有卷取机上切头的 shear_length 之和为切头量，所有卷取机上切尾的 shear_length 之和为切头量

#### 分卷产出

mat_type = 2 时，qm_mat_cells_blood 查询结果有多条入口物料不一样

### 数字钢卷切片数据生成

qm_mat_cells_blood 查询出来的行的 mat_type 的值都一致，成品卷的长度计算上卷取机的头尾剪切和卷取造成的头尾变换后可以对应到在线卷的长度，从而和工艺参数和表检仪式缺陷关联上

1. 根据入口物料相关字段在 qm_dc_coiler_log 中取对应开卷卷取方式。
   数据说明：qm_dc_coiler_log 中的开卷/卷取方式的第一位（uncoiler_method/coiler_method[0]）为 1 代表上，第一位为 9 代表下。
2. 根据入口物料相关字段在 qm_dc_shear_log 中取对应的剪切实绩。
   数据说明：剪切实绩的 shear_type 的第三位（shear_type[2]）代表剪切类型，1 代表切头，5 代表分切，9 代表切尾；shear_device_code 以 tr 开头表示卷取机，以 por 开头表示开卷机。
   - 如果 mat_type = 0，对于每个入口物料，取其剪切实绩，其中 shear_device_code 以 tr 开头 && shear_type[2] = '1' 的所有 shear_length 之和即为切头量，其中 shear_device_code 以 tr 开头 && shear_type[2] = '9' 的所有 shear_length 之和即为切尾量
