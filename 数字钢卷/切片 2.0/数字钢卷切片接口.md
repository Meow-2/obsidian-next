# 数字钢卷切片接口

## 接口路径

POST /api/quality/piece/output

## 入参

| 参数                 | 类型     | 必填  | 说明          |
| ------------------ | ------ | --- | ----------- |
| unitCode           | String | 是   | 机组代码        |
| outMatNo           | String | 是   | 出口物料号       |
| outMatRepeatProdNo | String | 是   | 出口物料重复生产次数号 |
| cellCode           | String | 是   | 加工单元代码      |

## 数字钢卷切片流程

### 基础数据初始化

1. qm_biz_digital_factory 表查询机组对应的数字钢卷切片存储的时序数据库、表名和精度
2. qm_biz_parameter 表查询机组对应的数字钢卷工艺参数的名字、类型、唯一键和存储的时序表和时序库
3. qm_mat_cells_blood 查询加工单元对应的入口出口物料流转情况，需要查询出包含完整分卷/并卷物料流转情况的记录

### 数字钢卷切片长度生成

在加工单元对应的入口出口物料流转情况中，取对应出口物料的长度，根据 qm_biz_digital_factory 配置的精度，对出口物料长度进行切片划分，每个切片有其 piece_no，对应着出口物料的一段长度

### 成品卷长度转在线卷长度前的数据准备

每个切片都对应一段成品卷长度。而成品卷的长度补上**卷取机的头尾剪切量**和**卷取造成的头尾变换**后可以对应到在线卷的长度，从而和跟踪数据的工艺参数和表检仪式缺陷关联上。

表数据使用说明：

1. qm_mat_cells_blood 查询结果的各行 mat_type 值都一样，取第一条的 mat_type 值即可。
2. qm_dc_shear_log 查询结果的剪切实绩中，shear_type 的第三位（shear_type[2]）代表剪切类型，1 代表切头，5 代表分切，9 代表切尾；shear_device_code 以 tr 开头表示卷取机，以 por 开头表示开卷机。
3. qm_dc_coiler_log 中的开卷/卷取方式的第一位（uncoiler_method/coiler_method[0]）为 1 代表上，第一位为 9 代表下。

#### 正常卷产出

 mat_type = 0 时，qm_mat_cells_blood 查询结果只有一条数据。

##### 卷取情况

1. qm_dc_coiler_log 表查询该入口物料的卷取方式

##### 卷取机头尾剪切量

1. qm_dc_shear_log 表查询该入口物料的剪切实绩
2. 计算该条数据的入口物料的在卷取机上的切头量、切尾量，所有卷取机上切头的 shear_length 之和为切头量，所有卷取机上切尾的 shear_length 之和为切尾量

#### 并卷产出

mat_type = 1 时，qm_mat_cells_blood 查询结果有多条入口物料不一样，出口物料一样的数据，out_mat_sequence_no 标明了多个入口物料的焊接顺序

##### 卷取情况

1. qm_dc_coiler_log 表查询多条入口物料的卷取方式

##### 卷取机头尾剪切量

1. qm_dc_shear_log 表查询多条入口物料的剪切实绩
2. 计算每条入口物料在卷取机上的切头量、切尾量，所有卷取机上切头的 shear_length 之和为切头量，所有卷取机上切尾的 shear_length 之和为切尾量

#### 分卷产出

mat_type = 2 时，qm_mat_cells_blood 查询结果有多条入口物料一样，出口物料不一样的数据，out_mat_sequence_no 标明了多个出口卷物料的切分顺序

##### 卷取情况

1. qm_dc_coiler_log 表查询入口物料的卷取方式

##### 卷取机头尾剪切量

1. qm_dc_shear_log 表查询入口物料的剪切实绩
2. 根据入口物料在卷取机上切头、切尾、分切量，所有卷取机上切头的 shear_length 之和为切头量，所有卷取机上切尾的 shear_length 之和为切尾量，对于分切，用 shear_no 区分每一次分切，卷取机上的 一次 shear_no 内的所有 shear_length 之和为分切量
3. 每个出口物料都有自己的切头量和切尾量，入口物料的切头量被算作是第一个出口物料的切头量，入口物料的每一次分切量被算作是下一个出口物料的切头量，入口物料的切尾量被算作是最后一个出口物料的切尾量。qm_dc_shear_log 记录的分切次数和实际分切次数不一定一致，qm_dc_shear_log 多的分切次数不用管，少的分切次数，后面的出口物料的切头量都按 0 算

### 成品卷长度转在线卷长度

在线卷包含最终保留的成品段，以及卷取机剪掉的头尾段。同一长度口径下，基本关系为：

```text
在线卷总长 = 成品卷长度 + 切头量 + 切尾量
```

所有长度单位统一为米。切头、切尾均按在线运行方向定义；在线坐标从最先通过设备的带头起算。上卷取、下卷取均反转头尾，因此成品带头对应在线保留段的尾端，成品带尾对应在线保留段的头端。换算只涉及剪切偏移、头尾反转以及分卷/并卷定位，区间长度保持不变。

```text
convertRange(context, a, b, onlineLengths) -> 多个 {入口物料标识, 在线起点, 在线终点}
```

- `context`：目标出口卷、完整分卷/并卷关系、成品长度及前文准备的剪切量。
- `[a,b]`：当前切片在目标成品卷上的长度范围，从成品带头起算。
- `onlineLengths`：各入口物料的完整在线总长 N，以入口物料号和重复生产次数号共同索引，坐标口径与跟踪数据的 `head_length` 一致。并卷时用于确定各入口贡献的成品长度；正常卷、分卷时可由成品长度和剪切量推得在线总长，实际在线总长用于校验。

#### 正常卷

设成品长 L，在线带头侧切头量 H，在线带尾侧切尾量 T，在线总长 N：

```text
N = H + L + T
在线保留段 = [H, N - T] = [H, H + L]
成品位置 p 对应在线位置 x = N - T - p = H + L - p
切片 [a,b] -> [H + L - b, H + L - a]
```

成品带头 p = 0 对应在线位置 N - T，成品带尾 p = L 对应在线位置 H。切尾量用于确定在线总长及保留段尾端，不应从成品长度中再次扣除。

例如 L = 100、H = 5、T = 3，则 N = 108，成品切片 [0,10] 对应在线区间 [95,105]，切片长度仍为 10 米。

#### 分卷

全部子卷按 `out_mat_sequence_no` 数值升序排列，即在线运行方向上的切分顺序。第 j 卷成品长 Lj，分配到该卷的切头、切尾量为 Hj、Tj，沿用前文规则：首卷承接入口切头，后续卷承接前一次分切，末卷承接入口切尾。

```text
N = sum(Hj + Lj + Tj)               // 同一入口的完整在线总长
Sj = sum(Hq + Lq + Tq, q < j) + Hj  // 第 j 卷在线保留段的起点
第 j 卷在线保留段 = [Sj, Sj + Lj]
成品位置 p 对应在线位置 x = Sj + Lj - p
切片 [a,b] -> [Sj + Lj - b, Sj + Lj - a]
```

全部子卷共用同一个入口在线坐标系，每个子卷在自己的保留段内反转头尾。分切量只计入下一卷 Hj，避免重复累计。

例如两卷 L1 = 40、L2 = 60，入口切头 5、分切量 2、入口切尾 3，则 N = 110，S1 = 5、S2 = 47。第二卷成品切片 [0,10] 对应在线区间 [97,107]。

#### 并卷

各入口按 `out_mat_sequence_no` 数值升序排列，即在线运行方向上的焊接顺序。成品总长 L，第 i 个入口的切头、切尾量为 Hi、Ti，完整在线总长为 Ni：

```text
Di = Ni - Hi - Ti                   // 第 i 个入口实际保留并贡献到成品中的长度
L = sum(Di)
sum(Ni) = L + sum(Hi + Ti)
Pi = L - sum(Dq, q <= i)            // 整体头尾反转后，第 i 个入口在成品中的起点
```

第 i 个入口覆盖成品区间 `[Pi, Pi + Di]`，对应其自身在线保留段 `[Hi, Ni - Ti]`。切片与该成品区间求交得到 `[s,e]`，若 `s < e`，返回该入口对应的在线区间：

```text
成品位置 p 对应该入口在线位置 x = Ni - Ti - (p - Pi)
[s,e] -> [Ni - Ti - (e - Pi), Ni - Ti - (s - Pi)]
       = [Hi + Di - (e - Pi), Hi + Di - (s - Pi)]
```

跨焊缝时返回多个入口区间，按成品坐标升序排列。计算需要全部入口的 Ni，不能仅传入一个入口长度；成品从头到尾对应的入口顺序与焊接顺序相反。只有成品总长和各入口剪切量，无法唯一确定各入口的保留长度及焊缝位置。

例如按顺序焊接入口 A、B，NA = 45、HA = 2、TA = 3，NB = 64、HB = 1、TB = 3，则 DA = 40、DB = 60，L = 100。成品区间 [0,60] 来自 B，[60,100] 来自 A；跨焊缝切片 [55,65] 对应 B 的在线区间 [1,6] 和 A 的在线区间 [37,42]，两段合计 10 米。

#### 调用要点

数据准备阶段保留完整血缘、成品长度和剪切量。正常卷、分卷的在线区间可在准备阶段确定；并卷还需要各入口的完整在线总长才能确定焊缝位置。读取各工艺段时，按入口标识和换算后的在线区间查询该段工艺参数。各入口在线坐标独立从 0 起算；各段使用相同在线长度坐标口径，数据时间范围可以不同。

要求成品长度、在线总长及并卷各 Di 大于 0，剪切量非负，切片满足 `0 <= a < b <= 目标成品卷长度`。并卷实际在线总长缺失、切片越界或长度关系不成立时，应报错并检查长度口径、血缘和剪切实绩；测量误差按业务约定的容差校验，不通过整体缩放掩盖差异。仅当另有明确的延伸或测量标定模型时，才单独引入对应的长度换算。

上述公式中的区间表示几何边界。查询时成品切片统一左闭右开、最后一片包含终点；反向映射后相应为左开右闭、最后一片包含在线下界。并卷焊缝按相邻成品区间的同一规则归属，避免边界数据重复。正常卷、分卷的映射区间长度应等于原切片长度；并卷跨焊缝返回的多个区间长度之和应等于原切片长度。
