# 数字钢卷跨工序切片表存储细则

使用 quality-ts 服务提供的接口来创建表、核对修改列、写入数据

每个机组有一张对应的数字钢卷跨工序切片表，存储在 TDengine 时序库中，具体的数据库名和表名在 qm_biz_digital_factory 表中配置

#### 表结构示例

该表的工艺参数字段列需要从 qm_biz_parameter 中获取，每次进行切片计算前，要先调用该接口获取最新的工艺参数字段，并更新数字钢卷切片表结构（只新增列，不删除列）

```sql
CREATE TABLE IF NOT EXISTS `<unit_code_lowercase>_overcell_piece_output` (
    `ts`                           TIMESTAMP,     -- 创建时间，精度由数据库配置决定
    `unit_code`                    VARCHAR(50),   -- 机组代码
    `final_mat_no`                 VARCHAR(50),   -- 最终成品物料号
    `final_mat_repeat_prod_no`     VARCHAR(50),   -- 最终成品重复生产次数号
    `out_mat_no`                   VARCHAR(50),   -- 出口物料号
    `out_mat_repeat_prod_no`       VARCHAR(50),   -- 出口物料重复生产次数号
    `cell_code`                    VARCHAR(50),   -- 加工单元代码
    `out_mat_start`                DOUBLE,        -- 出口物料起始长度，单位：米
    `out_mat_end`                  DOUBLE,        -- 出口物料结束长度，单位：米
    `piece_length`                 DOUBLE,        -- 切片精度，单位：米，由厚比决定，各工序的精度不同
    `piece_no`                     INT,           -- 切片序号，从1开始
    `defect_up_down_reverse`       BOOLEAN,        -- 表检缺陷上下表面是否反向
    `defect_os_ds_reverse`         BOOLEAN,        -- 表检缺陷操作侧传动侧是否反向
    `defect_os_trimming`           DOUBLE,         -- 表检操作侧累计切边量
    `defect_ds_trimming`           DOUBLE,         -- 表检传动侧累计切边量
    `defect_groups`                VARCHAR(16384)  -- 表检缺陷组标识的JSON数组文本，无缺陷时写入 []
) COMMENT '机组出口物料切片表';
```
