# 跨工序切片数据结构

跨工序物料跟踪号唯一标识：

```java
public OvercellPieceMatTrackKey {
    // 入口或出口物料跟踪号，由使用该键的集合明确方向
    String matTrackNo;
    String prodNo;
}
```

跨工序物料号唯一标识：

```java
public OvercellPieceMatKey {
    // 入口或出口物料号，由使用该键的集合明确方向
    String matNo;
    String repeatProdNo;
}
```

本加工单元成品卷切片基础数据结构：

```java
public OvercellPieceBaseData {
    OvercellPieceMatKey out_mat_key;
    OvercellPieceMatKey in_mat_key;
    OvercellPieceMatTrackKey out_mat_track_key;
    OvercellPieceMatTrackKey in_mat_track_key;
}
```

本加工单元成品卷切片在线卷数据：

```java
public OvercellPieceOnLineMatData {
}
```

本加工单元成品卷切片切片元数据：

```java
public OvercellPieceMetaData {
// 切片列表，每个切片有切片序号，这个序号和末加工单元的切片序号一致，但是长度是各加工单元上的成品卷长度
List<OverCellPieceRange> pieces;

// 本成品卷上下表面是否和末加工单元反向
Boolean up_down_reverse;

// 本成品卷左右方向是否和末加工单元反向
Boolean os_ds_reverse;

// 本成品卷左边的切片量（末加工单元对应到本成品卷位置后，离本成品卷最左边的距离）
Boolean os_trimming;

// 本成品卷右边的切片量（末加工单元对应到本成品卷位置后，离本成品卷最右边的距离）
Boolean os_trimming;
}
```
