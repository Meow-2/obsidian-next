## 接口路径

POST /api/quality/piece/overcell-output

## 入参

| 参数                 | 类型     | 必填  | 说明          |
| ------------------ | ------ | --- | ----------- |
| unitCode           | String | 是   | 机组代码        |
| outMatNo           | String | 是   | 出口物料号       |
| outMatRepeatProdNo | String | 是   | 出口物料重复生产次数号 |
| cellCode           | String | 是   | 加工单元代码      |

## 数字钢卷跨工序切片流程

### 生成各个加工单元成品卷的切片元数据

本加工单元成品卷切片元数据结构：

```
public class OverCellPieceMetaData {
    // 机组代码
    String unit_code;
    
    // 
    int 
    
    
    // 切片列表，每个切片有切片序号，这个序号和末加工单元的切片序号一致，但是长度是各加工单元上的成品卷长度
    List<OverCellPieceRange> pieces;
    
    // 本成品卷上下表面是否和末加工单元反向
    Boolean up_down_reverse;
    
    // 本成品卷左右方向是否和末加工单元反向
    Boolean os_ds_reverse;
    
    // 本成品卷左边的切片量（末加工单元对应到本成品卷位置后，离本成品卷最左边的距离）
    Boolean os_trimming;
    
    // 本成品卷右边的切片量（末加工单元对应到本成品卷位置后，离本成品卷最右边的距离）
    Boolean os_trimming;
};

public class OverCellPieceRange {
    // 末加工单元切片序号
    int pieceNo;
    // 本成品卷物料起始长度
    BigDecimal outMatStart;  
    // 本成品卷物料结束长度
    BigDecimal outMatEnd;
    // 际片长，单位米；末片可能小于配置片长，不另存一份可变长度  
    public BigDecimal getPieceLength() {  
        return outMatEnd.subtract(outMatStart);  
    }
}
```
