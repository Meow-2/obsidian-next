## 接口路径

POST /api/quality/piece/overcell-output

## 入参

| 参数                 | 类型     | 必填  | 说明          |
| ------------------ | ------ | --- | ----------- |
| unitCode           | String | 是   | 机组代码        |
| outMatNo           | String | 是   | 出口物料号       |
| outMatRepeatProdNo | String | 是   | 出口物料重复生产次数号 |
| cellCode           | String | 是   | 加工单元代码      |

## 数字钢卷跨工序切片流程

1. 跨工序物料跟踪树物料关系构建：OCPieceTreeNode
2. 跨工序跟踪基础数据构建：OCPieceBaseData
3. 跨工序物料跟踪树切片在线数据填充：OCPieceTreeNode 中的 OCPieceOnlineMatData
4. 跨工序物料跟踪树切片元数据填充：层序遍历树结构填充 OCPieceTreeNode 中的 OCPieceMetaData，本加工单元的入口卷切片和上加工单元的成品卷切片是一样的，所以在向前追溯的过程中，需要在本加工单元的完成本加工单元入口卷的切片转换并传递到上一加工单元作为其成品卷的切片，成品卷到入口卷的长度转化参照加工单元内的成品卷转在线卷，但是剪切不止要考虑卷取机的剪切，而是全部剪切实绩都要考虑，长度、左右、头尾的变化也要按成品卷和入口卷的变化来，其中切边量的计算，要根据在线卷转入口卷来决定左右是否要交换
5. 基于跨工序物料跟踪树，复用加工单位内切片逻辑，生成跨工序切片：
   注意跨工序切片的切片序号始终是按最终加工单元来的，长度起始和长度结束是按当前成品卷来的，成品卷长度转在线卷长度可以复用单工序的逻辑，另外还需要根据卷取方式，来确定是否发生左右变化和上下变化，叠加到成品卷切片的 os_ds_reverse 和 up_down_reverse 上，得到 defect_os_ds_reverse 和 defect_up_down_reverse，defect_os_trimming、defect_ds_trimming 和 os_trimming、defect_ds_trimming 保持一致
