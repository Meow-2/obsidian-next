# 跨工序数字钢卷切片相关数据源介绍

使用 Mybatis Plus 框架的 LambdaWrapper 读取相关数据库表；无法满足的查询使用 Mybatis XML SQL 完成。查询仅使用有效物料关系记录。

## Postgres quality 数据库

### 物料标识说明

| 标识 | 用途 |
| --- | --- |
| `out_mat_no + out_mat_repeat_prod_no + cell_code` | 定位某加工单元的一次成品卷产出，作为首次查询条件及后续切片对象的标识 |
| `in_mat_track_no + in_mat_prod_no` | 当前加工单元入口物料的跟踪标识，用于查找上一加工单元的出口 |
| `out_mat_track_no + out_mat_prod_no` | 加工单元出口物料的跟踪标识，与下一加工单元入口的跟踪标识匹配 |
| `in_mat_no + in_mat_repeat_prod_no + cell_code` | 定位当前加工单元的入口物料，用于后续关联在线跟踪数据及剪切等实绩 |

`in_mat_prod_no`、`out_mat_prod_no` 表示跟踪生产次数号，与 `in_mat_repeat_prod_no`、`out_mat_repeat_prod_no` 不能互相替代。

### qm_mat_cells_blood 机组内物料关系表

#### 作用一：从最终成品卷向前追溯全部加工单元的成品卷

首次查询关键字段：`out_mat_no + out_mat_repeat_prod_no + cell_code`，取自接口入参。

后续查询关键字段：`out_mat_track_no + out_mat_prod_no`，分别取当前记录的 `in_mat_track_no + in_mat_prod_no`。

查询结果关键字段：`id + unit_code + cell_code + out_mat_no + out_mat_repeat_prod_no + out_mat_track_no + out_mat_prod_no + in_mat_track_no + in_mat_prod_no + mat_type + out_mat_sequence_no`。

说明：

1. 首次查询取得最终成品卷的产出关系，将该卷加入待切片集合。
2. 使用当前入口的跟踪标识查找上一加工单元的出口，将命中的成品卷及衔接关系保存，再沿其入口继续向前查询，直到无记录。后续查询不限于入参的机组和加工单元，ZRM1 各道次采用相同规则。
3. 并卷保留全部入口关系，逐个追溯分支。待切片对象按 `out_mat_no + out_mat_repeat_prod_no + cell_code` 去重，关系记录按 `id` 区分；分支汇合时复用已展开结果，同一路径出现循环时报告异常。
4. 首次无记录表示最终成品卷关系缺失；后续无记录表示该分支结束。查询失败或跟踪标识不完整时报告异常。

上一加工单元的出口是下一加工单元的入口，匹配条件为：

```text
上一加工单元.out_mat_track_no = 当前加工单元.in_mat_track_no
上一加工单元.out_mat_prod_no  = 当前加工单元.in_mat_prod_no
```

查询示意：

```sql
-- 首次定位最终成品卷，参数取自接口入参。
SELECT *
FROM qm_mat_cells_blood
WHERE deleted = 0
  AND out_mat_no = :outMatNo
  AND out_mat_repeat_prod_no = :outMatRepeatProdNo
  AND cell_code = :cellCode;

-- 向前查找上一加工单元的出口，参数取当前记录的入口跟踪标识。
SELECT *
FROM qm_mat_cells_blood
WHERE deleted = 0
  AND out_mat_track_no = :currentInMatTrackNo
  AND out_mat_prod_no = :currentInMatProdNo;
```

#### 作用二：提供各成品卷切片所需的完整物料关系和跟踪数据定位信息

查询关键字段：`out_mat_no + out_mat_repeat_prod_no + cell_code`；分卷补查使用 `in_mat_no + in_mat_repeat_prod_no + cell_code`。

查询结果关键字段：`out_mat_no + out_mat_repeat_prod_no + in_mat_no + in_mat_repeat_prod_no + cell_code + mat_type + out_mat_sequence_no + out_mat_length + out_mat_thick + out_mat_width + start_prod_time + end_prod_time`。

说明：

1. 完整物料关系及校验沿用 [单工序数据源介绍](../单工序切片/数字钢卷切片相关数据源介绍.md) 和 [单工序切片接口](../单工序切片/数字钢卷切片接口.md) 的约定：`mat_type = 0` 为正常卷，`mat_type = 1` 为并卷，`mat_type = 2` 为分卷。
2. 并卷保留全部入口及拼接顺序；分卷按入口标识补查全部出口，按 `out_mat_sequence_no` 数值排序。补查的兄弟子卷仅用于完整分卷计算，不自动加入上游待切片集合。
3. 成品卷切片使用 `out_mat_repeat_prod_no`；入口在线跟踪数据按 `coil_no = in_mat_no`、`repeat_prod_no = in_mat_repeat_prod_no`、当前 `cell_code` 和生产时间范围查询。
4. `out_mat_length` 单位为米，`out_mat_thick`、`out_mat_width` 单位为毫米；生产时间与单工序查询使用相同时区。切片所需字段缺失时报告对应物料的数据不完整。

#### 表结构

复用 [单工序数据源介绍](../单工序切片/数字钢卷切片相关数据源介绍.md) 中的 `qm_mat_cells_blood` 定义。

## 基础数据准备结果

1. 最终成品卷及全部上游加工单元成品卷的待切片集合，按 `out_mat_no + out_mat_repeat_prod_no + cell_code` 标识，保留所属 `unit_code`。
2. 各加工单元的入口出口衔接关系，保留并卷分支及汇合关系。
3. 各待切片对象的完整物料关系、入口跟踪数据定位信息、出口尺寸和生产时间。

后续为每个待切片成品卷形成切片，并关联本次入参的最终成品卷。
