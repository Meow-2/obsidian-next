# 跨工序数字钢卷切片相关数据源介绍

## Postgres quality 数据库

### qm_mat_cells_blood 机组内物料关系表

#### 作用：查询当前成品卷在上一加工单元对应的成品卷

1. 按 `out_mat_no + out_mat_repeat_prod_no + cell_code` 查询当前成品卷的入口出口关系。
2. 取各入口的 `in_mat_track_no + in_mat_prod_no`，作为本表的 `out_mat_track_no + out_mat_prod_no` 查询，得到上一加工单元的成品卷及其入口出口关系。
3. 对于 unit_code 为 ZRM1 的

```sql
-- 当前成品卷的入口出口关系。
SELECT *
FROM qm_mat_cells_blood
WHERE deleted = 0
  AND out_mat_no = :outMatNo
  AND out_mat_repeat_prod_no = :outMatRepeatProdNo
  AND cell_code = :cellCode;

-- 向上追溯一次，参数取当前记录的入口跟踪标识。
SELECT *
FROM qm_mat_cells_blood
WHERE deleted = 0
  AND out_mat_track_no = :inMatTrackNo
  AND out_mat_prod_no = :inMatProdNo;
```

#### 正常卷、并卷、分卷

- 正常卷（`mat_type = 0`）：取唯一入口的跟踪标识向上查询。
- 并卷（`mat_type = 1`）：保留全部入口，分别按各入口的跟踪标识向上查询；`out_mat_sequence_no` 表示入口拼接顺序。
- 分卷（`mat_type = 2`）：按目标子卷对应的入口跟踪标识向上查询。需要完整分卷关系时，按 `in_mat_no + in_mat_repeat_prod_no + cell_code` 补查同次产出的全部出口，`out_mat_sequence_no` 表示出口分切顺序；兄弟子卷不作为目标卷的上游成品卷。

上述规则同样适用于上一加工单元的查询结果；同一出口对应多条并卷入口关系时，须全部保留。

返回成品卷的 `out_mat_no + out_mat_repeat_prod_no + cell_code` 用于后续切片。`in_mat_prod_no`、`out_mat_prod_no` 是跟踪生产次数号，不能用重复生产次数号替代。

### qm_biz_digital_factory 数字工厂

#### 作用：描述每个机组对应的数字钢卷切片存储的时序数据库、表名和精度

查询关键字段：code

查询结果关键字段：piece_length + piece_ts_database + piece_ts_table

说明：查询结果只有一条

1. code 字段为 unit_code
2. piece_ts_database 、piece_ts_table 为 TDengine 时序库中的表和表名，数字钢卷切片存储在时序库中，ts 写 create_time

#### 表结构

```sql
CREATE TABLE "qm_biz_digital_factory" ("id" bigint NOT NULL,
                                                "create_user"        BIGINT,
                                                "update_user"        BIGINT,
                                                "create_time"        TIMESTAMP WITHOUT TIME ZONE,
                                                "update_time"        TIMESTAMP WITHOUT TIME ZONE,
                                                "create_org"         BIGINT,
                                                "deleted"            INTEGER NOT NULL DEFAULT 0,
                                                "pid"                BIGINT,
                                                "code"               CHARACTER VARYING(50),
                                                "name"               CHARACTER VARYING(50),
                                                "type"               CHARACTER VARYING(50),
                                                "remark"             CHARACTER VARYING(2000),
                                                "seq"                BIGINT,
                                                "pids"               CHARACTER VARYING(500),
                                                "piece_length"       NUMERIC(10, 4),
                                                "piece_ts_database"  CHARACTER VARYING(100),
                                                "piece_ts_table"     CHARACTER VARYING(100),
                                                PRIMARY KEY ("id"));

COMMENT ON TABLE "qm_biz_digital_factory" IS '数字工厂';

COMMENT ON COLUMN "qm_biz_digital_factory"."id" IS '主键';

COMMENT ON COLUMN "qm_biz_digital_factory"."create_user" IS '创建人';

COMMENT ON COLUMN "qm_biz_digital_factory"."update_user" IS '更新人';

COMMENT ON COLUMN "qm_biz_digital_factory"."create_time" IS '创建时间';

COMMENT ON COLUMN "qm_biz_digital_factory"."update_time" IS '更新时间';

COMMENT ON COLUMN "qm_biz_digital_factory"."create_org" IS '创建部门';

COMMENT ON COLUMN "qm_biz_digital_factory"."deleted" IS '删除标记 0-已删除 1-未删除';

COMMENT ON COLUMN "qm_biz_digital_factory"."pid" IS '父节点id';

COMMENT ON COLUMN "qm_biz_digital_factory"."code" IS '编码';

COMMENT ON COLUMN "qm_biz_digital_factory"."name" IS '名称';

COMMENT ON COLUMN "qm_biz_digital_factory"."type" IS '类型：1工序；2机组';

COMMENT ON COLUMN "qm_biz_digital_factory"."remark" IS '说明';

COMMENT ON COLUMN "qm_biz_digital_factory"."seq" IS '顺序';

COMMENT ON COLUMN "qm_biz_digital_factory"."pids" IS '完整父id';

COMMENT ON COLUMN "qm_biz_digital_factory"."piece_length" IS '切片长度';

COMMENT ON COLUMN "qm_biz_digital_factory"."piece_ts_database" IS '出口卷切片表存储时序库名';

COMMENT ON COLUMN "qm_biz_digital_factory"."piece_ts_table" IS '出口卷切片表存储时序表名';

ALTER TABLE "qm_biz_digital_factory" OWNER TO "postgres";
```

### qm_biz_parameter 参数资源表

#### 作用：查询每个机组对应的参数的名字、类型、唯一键和存储的时序表和时序库

查询关键字段：unit_code + ts_database = 'digital_coil' + ts_table like '%ironloss/process%'

查询结果关键字段：name + unique_key + value_type + ts_table + ts_database

说明：查询结果有多条，查询时要对 ts_database 和 ts_table 列进行过滤，ts_database 为 digital_coil，ts_table 中要含有 process/ironloss 子串，代表由 process /ironloss 跟踪算法跟踪的结果

#### 表结构

```sql
CREATE TABLE "qm_biz_parameter" ("create_user" bigint,
                                          "create_org"          BIGINT,
                                          "create_time"         TIMESTAMP WITHOUT TIME ZONE,
                                          "update_user"         BIGINT,
                                          "update_time"         TIMESTAMP WITHOUT TIME ZONE,
                                          "deleted"             INTEGER,
                                          "id"                  BIGINT                 NOT NULL,
                                          "name"                CHARACTER VARYING(100) NOT NULL,
                                          "unique_key"          CHARACTER VARYING(100) NOT NULL,
                                          "value_type"          CHARACTER VARYING(50)  NOT NULL,
                                          "remark"              CHARACTER VARYING(500),
                                          "whole_backlog_code"  CHARACTER VARYING(255),
                                          "unit_code"           CHARACTER VARYING(255),
                                          "pos_code"            CHARACTER VARYING(255),
                                          "ts_table"            CHARACTER VARYING(255),
                                          "ts_database"         CHARACTER VARYING(255),
                                          PRIMARY KEY ("id"));

COMMENT ON TABLE "qm_biz_parameter" IS '参数资源表';

COMMENT ON COLUMN "qm_biz_parameter"."create_user" IS '创建人';

COMMENT ON COLUMN "qm_biz_parameter"."create_org" IS '创建组织';

COMMENT ON COLUMN "qm_biz_parameter"."create_time" IS '创建时间';

COMMENT ON COLUMN "qm_biz_parameter"."update_user" IS '更新人';

COMMENT ON COLUMN "qm_biz_parameter"."update_time" IS '更新时间';

COMMENT ON COLUMN "qm_biz_parameter"."deleted" IS '删除标记 0-未删除 1-已删除';

COMMENT ON COLUMN "qm_biz_parameter"."id" IS '主键';

COMMENT ON COLUMN "qm_biz_parameter"."name" IS '名称';

COMMENT ON COLUMN "qm_biz_parameter"."unique_key" IS '唯一键';

COMMENT ON COLUMN "qm_biz_parameter"."value_type" IS '值类型';

COMMENT ON COLUMN "qm_biz_parameter"."remark" IS '备注';

COMMENT ON COLUMN "qm_biz_parameter"."whole_backlog_code" IS '工序编码';

COMMENT ON COLUMN "qm_biz_parameter"."unit_code" IS '机组编码';

ALTER TABLE "qm_biz_parameter" OWNER TO "postgres";
```
