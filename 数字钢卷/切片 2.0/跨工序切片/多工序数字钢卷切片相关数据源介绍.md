# 多工序数字钢卷切片相关数据源介绍

跨工序切片的入参与[单工序数字钢卷切片接口](../单工序切片/数字钢卷切片接口.md)一致，包括 `unitCode`、`outMatNo`、`outMatRepeatProdNo`、`cellCode`。

基础数据准备从入参指定的最终成品卷出发，向前追溯所有工序的成品卷；遇到 ZRM1 机组时，进一步补齐机组内各加工单元的物料关系。最终成品卷和追溯得到的各成品卷均需形成切片，基础数据准备负责确定这些卷及其上下游关系，具体切片计算由后续流程完成。

使用 Mybatis Plus 框架的 LambdaWrapper 读取相关数据库表；无法满足的查询使用 Mybatis XML SQL 完成。查询仅使用有效物料关系记录。

## Postgres quality 数据库

### 物料标识说明

1. 单工序切片使用 `unit_code + cell_code + out_mat_no + out_mat_repeat_prod_no` 定位某加工单元的一次成品卷产出。
2. 机组间追溯使用 `out_mat_track_no + out_mat_prod_no` 定位出口物料，并以当前记录的 `in_mat_track_no + in_mat_prod_no` 查找上游出口物料。
3. `out_mat_prod_no` 是物料跟踪生产次数号，`out_mat_repeat_prod_no` 是供切片使用的重复生产次数号，两者不能直接等同。现有 `qm_mat_units_blood` 实体没有 `out_mat_repeat_prod_no` 字段，首次查询需要先完成标识转换；后续追溯到的物料也需要取得对应加工单元的重复生产次数号，才能对接切片。

### qm_mat_units_blood 机组间物料关系表

#### 作用：从最终成品卷向前追溯各工序的成品卷，建立跨机组物料关系

首次定位关键字段：入参 `unitCode + outMatNo + outMatRepeatProdNo + cellCode`，先取得对应的 `out_mat_track_no + out_mat_prod_no`。

查询关键字段：`out_mat_track_no + out_mat_prod_no`。

查询结果关键字段：`unit_code + backlog_code + out_mat_no + out_mat_track_no + out_mat_prod_no + in_mat_no + in_mat_track_no + in_mat_prod_no + mat_type + out_mat_sequence_no`。

说明：

1. 首次定位可按入参中的 `unit_code + cell_code + out_mat_no + out_mat_repeat_prod_no` 查询 `qm_mat_cells_blood`，取得出口物料的跟踪号和生产次数号，再查询 `qm_mat_units_blood`。这里读取机组内表是为转换标识，与 ZRM1 的机组内关系展开是两个用途。
2. 将首次查到的机组间关系记录作为追溯起点，保存其出口成品卷及所属机组。正常一对一场景下，当前出口物料对应一条关系记录。
3. 读取当前记录的 `in_mat_track_no` 和 `in_mat_prod_no`，分别作为下一次查询的 `out_mat_track_no` 和 `out_mat_prod_no`，继续查询本表。下一条记录的出口物料就是当前入口物料在上游的成品卷。
4. 重复上述过程，直到下一次查询没有记录，该分支的机组间追溯结束。后续查询不能一直限定入参的 `unitCode`，因为上游物料属于其他机组；应保留每条命中记录自身的 `unit_code`。
5. 若同一出口物料存在多条并卷入口关系，应沿每条入口关系分别向前追溯，保留全部上游分支，不能只取第一条。分卷时沿当前目标子卷对应的入口继续追溯，兄弟子卷是否参与计算所需的完整关系，按单工序规则另行补齐。
6. 对追溯结果保留物料标识和关系边，不能仅按物料号去重，以免合并同一物料的不同生产记录。重复遇到已展开节点时可复用结果；同一路径出现循环关系时应报错，避免无限追溯。
7. 命中 `unit_code = 'ZRM1'` 的物料时，还需要查询 `qm_mat_cells_blood`，补齐该物料在 ZRM1 机组内各加工单元的产出关系。本表负责机组间衔接，不能单独提供 ZRM1 全部加工单元的切片对象。

追溯条件示意：

```text
当前记录.in_mat_track_no → 上游记录.out_mat_track_no
当前记录.in_mat_prod_no  → 上游记录.out_mat_prod_no
```

首次定位无记录表示无法建立最终成品卷的追溯起点，应返回数据缺失；已建立起点后，向上游查询无记录才作为该分支的终点。数据库查询失败不能当作无上游处理。

### qm_mat_cells_blood 机组内物料关系表

#### 作用一：衔接切片入参与机组间物料标识，为各成品卷提供切片定位信息

查询关键字段：`unit_code + cell_code + out_mat_no + out_mat_repeat_prod_no`。

查询结果关键字段：`out_mat_track_no + out_mat_prod_no + out_mat_no + out_mat_repeat_prod_no + unit_code + cell_code`。

说明：

1. 将最终成品卷的切片标识转换为机组间表使用的跟踪标识，作为 `qm_mat_units_blood` 首次查询的依据。
2. 对机组间追溯得到的出口物料，可反向按 `unit_code + out_mat_track_no + out_mat_prod_no` 查询本表，取得其加工单元和出口物料重复生产次数号，形成后续切片所需的定位信息。不同加工单元的产出应分别保留，不能任取一条。
3. 关键跟踪标识、重复生产次数号或加工单元缺失时，应报告对应物料的数据不完整，不能用生产次数号直接代替重复生产次数号。

#### 作用二：补齐 ZRM1 机组内各加工单元的入口出口物料关系

查询关键字段：`unit_code = 'ZRM1' + out_mat_track_no + out_mat_prod_no`；具体加工单元的产出使用 `cell_code + out_mat_no + out_mat_repeat_prod_no` 区分。

查询结果关键字段：`cell_code + out_mat_no + out_mat_repeat_prod_no + out_mat_track_no + out_mat_prod_no + in_mat_no + in_mat_repeat_prod_no + in_mat_track_no + in_mat_prod_no + mat_type + out_mat_sequence_no + out_mat_length + start_prod_time + end_prod_time`。

说明：

1. 以机组间追溯命中的 ZRM1 出口物料为入口，查询该物料对应的机组内关系，取得相关加工单元的成品卷，补齐仅查询机组间表无法得到的机组内生产过程。
2. 对需要继续向前展开的机组内入口物料，以其 `in_mat_track_no + in_mat_prod_no` 匹配本表的 `out_mat_track_no + out_mat_prod_no`，并限定 `unit_code = 'ZRM1'`。同一跟踪标识对应多个加工单元时，应保留全部相关加工单元记录，不能只取第一条，也不能只按跟踪标识去重而丢失道次。
3. 机组内关系应按实际入口出口衔接展开，`cell_code` 用于区分加工单元，不能仅凭加工单元编号推断血缘。同一路径重复命中同一关系记录时应检测循环；同一出口节点的多条合法入口关系仍需全部保留。
4. 机组内向前查询无记录时，结束该机组内分支；机组间的上游衔接仍由 `qm_mat_units_blood` 提供，两张表的结果合并保存。若同一产出同时出现在两张表中，按机组、加工单元、出口物料号和重复生产次数号合并切片对象，保留各自的关系信息。
5. 正常卷、并卷、分卷的完整物料关系沿用[单工序数据源介绍](../单工序切片/数字钢卷切片相关数据源介绍.md)中本表的规则：`mat_type = 0` 为正常产出；`mat_type = 1` 保留所有入口及拼接顺序；`mat_type = 2` 需按入口物料和加工单元补查全部出口及分切顺序。补查的兄弟子卷用于还原完整分卷关系，不自动视为最终成品卷的上游祖先。
6. 每个需切片的加工单元成品卷保留出口长度、入口物料、生产时间、关系类型和顺序号，供后续复用单工序的数据准备与长度换算逻辑。`out_mat_length` 单位为米；生产时间保持与单工序查询一致的时区口径。

#### 表结构

`qm_mat_cells_blood` 表结构复用[单工序数据源介绍](../单工序切片/数字钢卷切片相关数据源介绍.md)中的定义。

## 基础数据准备结果

准备完成后，应得到最终成品卷及全部上游工序成品卷的集合、ZRM1 相关加工单元的成品卷集合，以及这些产出之间的入口出口关系。每个待切片对象均包含 `unit_code + cell_code + out_mat_no + out_mat_repeat_prod_no`，同时保留跟踪标识用于追溯关联。后续对每个对象形成切片，并保留其与入参最终成品卷的关联。
