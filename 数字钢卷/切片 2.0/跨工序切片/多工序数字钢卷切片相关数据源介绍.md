# 跨工序数字钢卷切片相关数据源介绍

## Postgres quality 数据库

### qm_mat_cells_blood 机组内物料关系表

#### 作用：查询当前成品卷

#### 作用：查询当前成品卷在上一加工单元对应的成品卷

1. 按 `out_mat_no + out_mat_repeat_prod_no + cell_code` 查询当前成品卷的入口出口关系。
2. 取各入口的 `in_mat_track_no + in_mat_prod_no`，作为本表的 `out_mat_track_no + out_mat_prod_no` 查询，得到上一加工单元的成品卷及其入口出口关系。
3. 对于 unit_code 为 ZRM1 的

```sql
-- 当前成品卷的入口出口关系。
SELECT *
FROM qm_mat_cells_blood
WHERE deleted = 0
  AND out_mat_no = :outMatNo
  AND out_mat_repeat_prod_no = :outMatRepeatProdNo
  AND cell_code = :cellCode;

-- 向上追溯一次，参数取当前记录的入口跟踪标识。
SELECT *
FROM qm_mat_cells_blood
WHERE deleted = 0
  AND out_mat_track_no = :inMatTrackNo
  AND out_mat_prod_no = :inMatProdNo;
```

#### 正常卷、并卷、分卷

- 正常卷（`mat_type = 0`）：取唯一入口的跟踪标识向上查询。
- 并卷（`mat_type = 1`）：保留全部入口，分别按各入口的跟踪标识向上查询；`out_mat_sequence_no` 表示入口拼接顺序。
- 分卷（`mat_type = 2`）：按目标子卷对应的入口跟踪标识向上查询。需要完整分卷关系时，按 `in_mat_no + in_mat_repeat_prod_no + cell_code` 补查同次产出的全部出口，`out_mat_sequence_no` 表示出口分切顺序；兄弟子卷不作为目标卷的上游成品卷。

上述规则同样适用于上一加工单元的查询结果；同一出口对应多条并卷入口关系时，须全部保留。

返回成品卷的 `out_mat_no + out_mat_repeat_prod_no + cell_code` 用于后续切片。`in_mat_prod_no`、`out_mat_prod_no` 是跟踪生产次数号，不能用重复生产次数号替代。

### qm_biz_digital_factory 数字工厂

#### 作用：描述每个机组对应的数字钢卷切片存储的时序数据库、表名和精度

查询关键字段：code

查询结果关键字段：piece_length + piece_ts_database + oc_piece_ts_table

说明：查询结果只有一条

1. code 字段为 unit_code
2. piece_ts_database 、oc_piece_ts_table 为 TDengine 时序库中的表和表名，跨工序数字钢卷切片存储在时序库中，ts 写 create_time
3. 每个机组一个 oc_piece_ts_table，但实际存储时的 piece_length 字段只有最后一个加工单元是从 qm_biz_digital_factory 中来的，向前追溯的加工单元的 piece_length 根据该加工单元的具体长度计算

#### 表结构

```sql
CREATE TABLE "qm_biz_digital_factory" ("id" bigint NOT NULL,
                                                "create_user"        BIGINT,
                                                "update_user"        BIGINT,
                                                "create_time"        TIMESTAMP WITHOUT TIME ZONE,
                                                "update_time"        TIMESTAMP WITHOUT TIME ZONE,
                                                "create_org"         BIGINT,
                                                "deleted"            INTEGER NOT NULL DEFAULT 0,
                                                "pid"                BIGINT,

                                                "name"               CHARACTER VARYING(50),

                                                "piece_ts_table"     CHARACTER VARYING(100),
                                                "oc_piece_ts_table"  CHARACTER VARYING(100),
```
