# 跨工序切片关键数据结构

## 物料跟踪树

### 跨工序物料跟踪树节点

```java
@Data
public class OCPieceTreeNode {
    private String unitCode;
    private String cellCode;
    private OCPieceMatTrackKey outMatTrackKey;
    private OCPieceMatKey outMatKey;
    // 该加工单元的完整关系；并卷按入口焊接顺序、分卷按全部出口切分顺序排列，不允许重复。
    private List<MatCellsBoold> relations;
    private Map<OCPieceMatTrackKey, OCPieceTreeNode> lastCells;
    
    // 构建树时不赋值
    private List<OCPMatKey, OCPieceOnlineMatData> pieceOnlineMatDatas;
    // 构建树时不赋值
    private OCPieceMetaData pieceMetaData;
}
```

### 加工单元成品卷切片切片元数据

```java
@Data
public class OCPieceMetaData {
    // 切片列表，每个切片有切片序号，这个序号和末加工单元的切片序号一致，但是长度是各加工单元上的成品卷长度
    private List<OCPieceRange> pieces;
    
    // 本成品卷上下表面是否和末加工单元反向
    private Boolean up_down_reverse;
    
    // 本成品卷左右方向是否和末加工单元反向
    private Boolean os_ds_reverse;
    
    // 本成品卷左边的切片量（末加工单元对应到本成品卷位置后，离本成品卷最左边的距离）
    private Boolean os_trimming;
    
    // 本成品卷右边的切片量（末加工单元对应到本成品卷位置后，离本成品卷最右边的距离）
    private Boolean os_trimming;
}


public class OCPieceRange {
}
```
