### 跨工序物料跟踪树节点

```java
public OCPieceTreeNode {
    String unitCode;
    String cellCode;
    OCPieceMatTrackKey outMatTrackKey;
    OCPieceMatKey outMatKey;
    // 该加工单元的完整关系；并卷按入口焊接顺序、分卷按全部出口切分顺序排列，不允许重复。
    List<MatCellsBoold> relations;
    Map<OCPieceMatTrackKey, OCPieceTreeNode> lastCells;
    
    // 构建树时不赋值
    List<OCPMatKey, OCPieceOnlineMatData> pieceOnlineMatDatas;
    // 构建树时不赋值
    OCPieceMetaData pieceMetaData;
}
```

### 加工单元成品卷切片切片元数据

```java
public OCPieceMetaData {
    // 切片列表，每个切片有切片序号，这个序号和末加工单元的切片序号一致，但是长度是各加工单元上的成品卷长度
    List<OCPieceRange> pieces;
    
    // 本成品卷上下表面是否和末加工单元反向
    Boolean up_down_reverse;
    
    // 本成品卷左右方向是否和末加工单元反向
    Boolean os_ds_reverse;
    
    // 本成品卷左边的切片量（末加工单元对应到本成品卷位置后，离本成品卷最左边的距离）
    Boolean os_trimming;
    
    // 本成品卷右边的切片量（末加工单元对应到本成品卷位置后，离本成品卷最右边的距离）
    Boolean os_trimming;
}
```
