# 跨工序追溯界面数据映射关系

## 坐标与身份

| 数据 | 口径 |
| --- | --- |
| 工序卡刻度、框选、缺陷位置 | 当前显示节点的出口成品坐标，带头 0，单位米 |
| 最终片号 | 同一最终卷的关联键。结合节点、路径使用，上游可稀疏 |
| 来料位置 | 每个入口边指向的上游节点自己的成品坐标，保留母卷标识 |
| 横向几何与切边 | 毫米及明确的操作侧／传动侧轴，见[缺陷展示](展示缺陷时如何处理切片量.md) |

每条工序卡独立换算米值到画布像素。缩放视窗时由可见米制起止决定显示比例。各卡像素位置、长度比例及原型 `scale/offset` 都不能作为真实跨工序对应关系。

## 选区投影

1. 保存原始节点与实际选区 `[start, end)`，验入参为有限小数、`0 ≤ start < end ≤ 当前卡坐标总长`。拖拽端点先排序并裁到当前可见轴，数字精调非法时保留上一次有效选区。
2. 用 `piece.start < end && piece.end > start` 在原节点已加载数据中选出命中的最终片号。在目标节点及当前母卷分支内查找同片号。原始选区与各节点的映射结果分别保存。切换卡片只改变目标节点，只有重新拖拽或提交数值才更改锚点。
3. 现有结果只有各节点完整片区间，基线界面将目标命中的片段按米值排序并合并相邻段，保留不连续区间。跨母卷按边分组。标注「按切片映射」，无对应片时提示「暂无对应切片」或「未加载」。
4. 若提供片内精确映射，读服务需返回实际分支贡献段及有向端点／映射关系，使页面能区分头尾、翻转和剪切偏移。公式复用[跨工序切片映射](../跨工序切片/数字钢卷切片计算过程中的数据映射关系.md)。现有落库端点均按大小升序，不能凭端点线性同向插值恢复方向。

例：当前卷的框选命中最终片号 70、71、72，前两片对应母卷 A 的 `[18,24)`，最后一片对应母卷 B 的 `[122,125)`。两支各自标注，不能合成 `18–125 m`。若母卷 B 缺少 72 号结果，则只显示 A 的已知映射并标明 B 缺数据。

轧机折叠主卡的坐标采用组内最下游实际道次。展开后道次卡可复用原型的工序基准尺来精调，必须标注基准道次；指标按选中道次的真实片区间与参数计算。需要在道次卡直接展示自身长度时，先将同一选区按片号投影，再用本道次刻度渲染。

## 缺陷筛选

直接检出的缺陷位置采用当前节点的 `defect_groups` 前缀并保留后台片归属。按节点／来源卷、显示表面、已应用的缺陷类型和等级及选区过滤，同一批结果供画布、列表和汇总使用。仅有位置点时按选区左闭右开过滤；精确纵向区间可用相交判断。跨节点只知道片号时，用该片段做品红映射高亮并标出来源工序，禁止将它计入目标工序检出数量。

## 工艺指标和趋势

- 与范围相交的切片作为统计样本，按机组、加工单元和参数键取值，保留实际片号。未框选时取当前母卷视图的所有可用切片。
- 以切片值实现时，平均为有效片均值的算术平均，最小、最大为片均值的极值。显示「切片统计」，和原始采样统计区分。只排除 NULL 或无效数值，保留 0；无有效值不判异常。右栏可显示这一统计覆盖的有效片数，便于理解缺行与缺参。
- 有标准时注明配置适用的工序、道次及比较依据。沿用原型可按均值与闭区间比较，业务另有规则时以确认后的标准为准。没有标准或单位不一致时显示状态，禁止以原型示例区间代替。
- 切片趋势横轴为节点成品米值，可用片中心作显示点并保留真实片区间。片间缺口与空值不连线、不补零；渲染范围及面板统计共享选区和参数集合。
