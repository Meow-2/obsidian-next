# 跨工序追溯界面流程

[安阳-跨工序追溯.html](安阳-跨工序追溯.html)定义功能分区和操作入口。正式页面保留顶部筛选、左侧钢卷对齐和右侧分析区，表单、按钮和分栏卡片沿用质量系统的组件样式。原型的固定钢卷、七张工序卡、五道次、示例图像和模拟曲线用于演示。

## 界面模块职责

| 模块 | 负责内容 | 与其他模块的联动 |
| --- | --- | --- |
| 顶部筛选 | 按材料号、生产时间和机组检索候选，选定具体主物料档；应用缺陷类型和严重等级筛选 | 主档决定整页追溯对象；缺陷条件应用到缺陷画布、列表和汇总 |
| 跨工序钢卷对齐 | 展示实际追溯路径、工序卡和道次、母卷分支及可定位的区间；支持工序、道次、来源卷、显示面和米制选区切换 | 当前路径、节点和选区决定右栏的分析范围；选区按共同最终片号映射到其他节点，画布接收缺陷定位 |
| 缺陷列表 | 列出当前表检范围内命中的缺陷，提供单条选择 | 列表、页签计数和汇总共用同一组过滤结果；点选后更新详情并在对齐区高亮位置 |
| 缺陷汇总 | 展示当前缺陷总数及按类型、严重等级的数量和占比 | 随列表过滤结果刷新，占比以当前列表缺陷总数为分母 |
| 缺陷详情 | 展示选中缺陷的来源、位置、可用属性及图片 | 随列表选中项更新；选中缺陷只更新定位和详情，工艺指标仍使用手动选区 |
| 工艺指标 | 展示当前工序或道次的参数统计、标准范围和状态，有正式来源时展示道次规程 | 使用对齐区提供的节点及有效范围，按已选参数或主题刷新 |
| 参数与主题 | 检索和选择参数，应用、覆盖或另存主题 | 将已选参数交给指标表与趋势图；主题保存由相应权限控制 |
| 工艺参数趋势图 | 展示已选参数在当前范围内的变化，标明采样粒度 | 与指标表共用节点、范围和参数集合；切片趋势按当前节点的成品米值绘制 |
| 钢卷档案弹窗 | 展示关键指标、全流程履历、工序明细、母卷构成与缺陷档案 | 从对齐区打开，标题使用当前工序的出口卷号，履历使用顶部所选主档的追溯树 |

## 首版实现范围

打开跨工序对齐页面 `/#/qm/dc/overcell-align`，按材料号选定主档，即可查询实际工序节点和切片。该路由沿用数字钢卷的访问权限。页面支持按共同片号框选联动、查看母卷分段、展开实际轧制道次、查看已存表检引用、按片统计工艺指标和查看切片趋势。接口见[首版页面接口](跨工序追溯界面接口.md)。

精确焊缝和片内映射需要母卷贡献段。里侧／外侧、缺陷类别、等级及详情图片需要现场标定或表检源接入。工艺标准、道次规程和共享参数主题需要正式配置来源。

## 顶部筛选

- 材料号必填，支持输入片段和下拉选择。候选按时间和机组收窄，显示能区分同号记录的机组、生产时间和跟踪生产次数。选择项绑定主物料档 ID；输入命中多条时要求选择具体记录。
- 生产时间和机组筛选物料候选，缺陷类型和严重等级筛选所选卷的表检结果。修改输入只更新候选或待应用条件，点「查询」后提交追溯条件。查询和过滤分工见[界面接口](跨工序追溯界面接口.md)。
- 校验不通过时，提示具体原因并保留最后一次成功结果及其已生效的材料标识。成功切换主档后重新初始化当前工序、道次、来源卷、手动范围和缺陷焦点。只改缺陷过滤条件时保留工序和手动范围，焦点若被过滤则清除。
- 「重置」清除条件和联动选择并恢复系统默认显示。原型预置的演示卷和日期不作为生产默认值。未选卷的首屏提示选择材料；载入时标明当前请求，晚返回的旧请求不得覆盖新选择。

## 左侧钢卷对齐

| 原型操作 | 开发行为 |
| --- | --- |
| 工序卡、相对原料、母卷条、焊缝标记 | 按真实追溯树渲染。每张卡标明自己的成品长度坐标；相对原料逐入口展示上游对应区间。母卷条、接缝和上游区间仅在定位依据充分时绘制 |
| 点击工序卡 | 切换右栏数据口径。已有手动范围通过共同最终片号投影到新节点，保留原始选择锚点；无可映射范围时提示并保留选区状态 |
| 拖拽、起止值精调、双击清除 | 拖拽预览，提交时计算区间；支持键盘输入米值。当前节点蓝色显示，其他节点显示映射区间。双击清除范围和缺陷焦点 |
| 加工单元展开或收起 | 同一条路径中连续的同机组轧制道次作为一组；默认以最下游的实际道次显示主卡，展开后按道次倒序。按完整三位后缀排序，选中道次决定指标取值的加工单元 |
| 全部母卷或单一母卷 | 用入口身份和分支标识选择。仅限制当前追溯上下文，不切换顶部选中的主物料档。切到可映射的母卷时保留相交范围，无相交时清除当前焦点并给出范围提示 |
| 里侧 / 外侧 | 默认可沿用原型外侧。此为最终成品显示面的选择，需由现场确认它与最终上、下表面的对应关系；口径见[缺陷展示](展示缺陷时如何处理切片量.md) |
| 查看钢卷档案 | 在当前页面打开独立弹窗，高亮当前工序并展示其整卷表检引用。母卷区间按已加载的共同片号展示，缺少数据的字段留空 |

工序卡至少区分「有切片」「无切片记录」「读取失败」「仅追溯」。仅当已知配置排除该单元产片时显示「仅追溯」。如提供全路线占位，只有经过现场路线配置确认的未经过工序才标「本卷未流经」。树分支终止或结果缺行时显示相应的数据状态。

## 右侧缺陷和工艺指标

- 有表检能力的工序展示「缺陷列表 / 工艺指标」页签；有能力且查询成功但无命中时，缺陷页签显示 0 和空状态。无表检的工序展示工艺指标，可跳到可用表检节点；同卷有多个表检节点时可选来源。
- 缺陷列表、右上角计数和类型／严重等级汇总消费同一组过滤结果。点击缺陷高亮列表、更新详情，并以品红显示检测位置或对应片段。选中缺陷不改手动范围的统计口径；当焦点高亮出现时暂时隐藏蓝色带。点击空白清焦点，开始新拖拽时也清除焦点。
- 工艺指标按当前工序或道次与有效范围计算。原型表列包括参数、来源、平均、最小、最大、标准范围和状态。标准或值缺失时显示对应空状态；计算见[数据映射](跨工序追溯界面数据映射关系.md)。
- 「添加参数」按工序与分组检索，已选集合用机组和参数键识别；「查询」按已选参数刷新统计。主题选择替换参数集，「不使用主题」解除绑定并保留当前参数；覆盖与另存按主题权限启用。道次规程、趋势图、缺陷图片及档案详情遵循[数据源](跨工序追溯界面数据源介绍.md)中的可用性约定。

## 验收场景

| 场景 | 预期 |
| --- | --- |
| 同材料号存在两次产出，旧请求晚返回 | 必须选择具体主档，最终显示最后一次提交对应的卷 |
| 上游并卷出现两支、其中一支切片缺行 | 两个来源分别显示，缺行分支仍可看血缘；缺口不补画 |
| 切换工序、实际道次、母卷 | 始终按所选路径和加工单元取值，范围可往返且不扩大；无映射时明确提示 |
| 有表检但本范围为空、无表检、查询失败 | 三种状态可区分；统计口径与列表一致 |
| 点缺陷、再拖选、输入起止、双击 | 品红焦点与蓝色带按交互规则切换；鼠标和键盘提交的同一范围得到相同结果 |
| 部分参数为空或无标准 | 趋势显示间断，参数表提示暂无有效值或未配置标准；图表与指标使用一致的样本范围 |
