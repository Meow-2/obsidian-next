# 跨工序数字钢卷切片相关数据源介绍

## Postgres quality 数据库

与单工序共用实体和 master 数据源，各准备阶段在独立只读快照内执行。字段基础含义见[单工序数据源](../单工序切片/数字钢卷切片相关数据源介绍.md)，本页说明跨工序新增用途及差异。

### qm_mat_cells_blood 机组内物料关系表

#### 作用一：当前成品在本加工单元内的完整关系

根节点四字段定位出口；正常卷一行，并卷多入口同出口，分卷按相同入口号及重复次数补齐全部已知出口。mat_type、成品长度、业务顺序、重复关系的校验沿用 PieceBaseDataReader。

#### 作用二：从当前入口追溯上一加工单元出口

```sql
-- 语义示例；候选筛选后还需按加工单元顺序选择并检查歧义。
SELECT * FROM qm_mat_cells_blood
WHERE deleted = 0
  AND out_mat_track_no = :currentInMatTrackNo
  AND out_mat_prod_no = :currentInMatProdNo;
```

查询不先限制机组，依靠加工单元顺序从全部候选中选最近前序。跟踪次数保持原始字符串，不转数值，不与 repeat_prod_no 混用。候选选定后重新补齐该上游正常/并卷/分卷完整关系。

| 字段组 | 用途与约束 |
| --- | --- |
| in_mat_track_no + in_mat_prod_no | 当前入口连接键；可同时缺失以终止追溯，半缺失非法 |
| out_mat_track_no + out_mat_prod_no | 当前/候选出口跟踪身份，必须完整；同节点物料身份需与跟踪身份一致 |
| in/out_mat_no + in/out_mat_repeat_prod_no | 各节点本地查询实绩、工艺和最终清理的物料号身份，不替代跟踪键 |
| unit_code + cell_code | 定位节点，cell_code 决定路线顺序、默认开卷卷取及是否产片 |
| out_mat_length | 当前出口实长，米；向前映射用上游目标出口实长作为入口坐标总长 |
| out_mat_sequence_no | 并卷焊接或分卷切分顺序，从 1 连续；按数值排序 |
| start/end_prod_time | 每入口合并生产窗；结束必填，开始逐行兜底为结束前 2h，再扩展 ±1h |

### 加工单元路线配置

来源为代码 `OCPieceCellProfile`，不是另一个数据库路线表。编码查找可去空白、转大写，但原始关系查询不自动改写 cellCode。

| 加工单元 | traceOrder | 默认开卷 | 默认卷取 | 处理 |
| --- | --- | --- | --- | --- |
| YL001 | 1000 | 无 | 无 | 原料起点，保留树节点及实长，终止追溯，不产片 |
| CP1001 | 2000 | 11 | 19 | 产片 |
| CBL1001 | 3000 | 11 | 19 | 产片 |
| ZRM1 + 三位道次 | 4000 + 道次 | 首道 11，后续 91 | 99 | 道次为 001..999，产片 |
| DCL1001 | 5000 | 11 | 19 | 产片 |
| BAF1001 | 6000 | 无 | 无 | 罩式炉，仅追溯，坐标一进一出穿透 |
| FCL1001 | 7000 | 11 | 19 | 产片 |
| CSL1001 | 8000 | 11 | 19 | 产片 |

方向仅看编码首位：1 上、9 下，不能将 19 看成下卷取。ZRM1010 表示第 10 道，顺序 4010；不以单个末位字符判断道次。未知单元或非法轧机编码失败；上游顺序必须严格更早，允许跳过没有候选记录的工序，不强制每条路线齐全。

### qm_biz_digital_factory 数字工厂

按产片节点机组去重加载唯一有效配置。piece_ts_database 和 oc_piece_ts_table 必填，piece_ts_table 不作跨工序产出前置条件。只有最终机组的 piece_length 必须正数；上游切片直接继承映射，不使用上游配置片长重新划分。

另读取全部有效机组配置用于历史结果清理。跨工序表与任何已配置单工序表不得重合，同路径不同机组不得共用跨工序结果表。结果库和表名来自配置，不根据机组名拼接。

### qm_biz_parameter 参数资源表

与单工序筛选条件一致：digital_coil 库，process/ironloss 表名，float/short/int/long/double/byte 数字类型，按 unique_key 排序。每个产片机组参数列表必须非空，忽略大小写检查重复及跨工序固定列冲突。各机组独立参数集合、各来源表独立在线长度；动态结果列统一 DOUBLE。

### qm_dc_shear_log 剪切实绩表

按 unit_code + cell_code + 入口物料号和重复次数读取全部设备，不按生产窗裁剪，单刀长度已是米。

| 汇总结果 | 设备范围 | 分组与排序 | 用途 |
| --- | --- | --- | --- |
| trHead、trTail | tr 前缀卷取机 | 分别累计第三位为 1、9 的长度 | 节点内成品→工艺/表检在线 |
| trSlice | tr 前缀卷取机 | 设备代码+shear_no 分组，首刀时间排序，截断/补零到 n−1 | 节点内分卷换算 |
| head、tail | 所有设备 | 累计切头、切尾，已包含 tr 系列，不可重复相加 | 当前成品→上游成品 |
| slice | 所有设备 | 设备代码+shear_no 分组，按时间、设备、组号稳定排序；补零但保留额外组 | 跨节点分卷偏移 |

不同设备相同 shear_no 是不同组。n 是当前完整关系中的已知出口数。全部设备额外分切组保留用于发现无法定位的实绩；非空片分卷跨节点映射要求其数量恰为 n−1，不能静默截断。

### qm_dc_coiler_log 开卷卷取实绩表

每个产片节点入口按 cell_code + in_mat_no + in_mat_repeat_prod_no 查询最新记录，create_time DESC NULLS LAST、id DESC。读取 uncoiler_method 和 coiler_method，两者分别校验/兜底。

无记录或某字段空白时使用本加工单元默认值；非空但首位不是 1/9 则失败，不回退旧记录，不覆盖合法实绩。此规则适用于全部跨工序产片节点，与单工序 CP1/FCL1 必须有实际卷取记录的要求不同。

### qm_dc_trimming_log 切边实绩表

| 字段 | 类型/单位 | 使用与约束 |
| --- | --- | --- |
| unit_code、cell_code、in_mat_no、in_mat_repeat_prod_no | String | 按当前节点和入口联合定位 |
| trimming_length | String→BigDecimal，毫米 | 单侧切边，两侧各切该值；需非负十进制文本 |
| create_time | LocalDateTime，Asia/Shanghai | 取最新记录；NULL 排后，同时间按 id 降序 |
| id、deleted | Long、Integer | 主键与逻辑删除 |

无记录返回 0；有记录但值缺失或非法则失败。该表只有单侧统一切边量，当前输入不能表达左右不对称本工序切边，但累计距离的两侧仍分别维护、随方向交换。

## TDengine digital_coil 数据库

### 工艺参数表

读取逻辑复用 PieceSampleReader：同一实际库表、入口、加工单元、扩展时间窗读全部必要 head_length 和参数值。每段最大位置来自该批原始采样，而不是上游成品实长。任一入口缺正在线长度整段 NULL，SQL 异常等仍使节点失败；全部段无效则节点失败。

缓存仅存在一次跨工序查询请求内，以机组、加工单元、入口 MatKey、完整 ProdTimeWindow、PieceTable 联合标识，避免不同生产窗口或路径错误复用。缓存原始数据，不复用路径相关的已换算结果。

### qm_defect_surface_check_monthly 表检月超级表

仅 CP1/FCL1 使用，过滤条件与单工序一致：机组、结束月份 YYYY_MM、入口物料号、扩展 ts 窗口。保留 ts、source_id 联合身份和 y_position；当前跨工序查询不校验 up_down 的 0/1，表面方向由累计标志交给消费者解释。

表检纵向坐标用各入口最大 y_position，全部入口无记录时无缺陷且不限制片号；并卷仅部分入口有表检时节点失败。独立调用 convertMapped，不固定工艺段并卷边界。

跨工序身份格式为 `成品位置@@unit_code@@end_month@@in_mat_no@@ts@@source_id`，与单工序中入口号的位置不同；前缀为当前节点成品坐标，不是最终卷坐标。
