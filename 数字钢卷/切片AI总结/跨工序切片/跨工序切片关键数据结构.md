# 跨工序切片关键数据结构

以下为当前 Java 实现的字段说明，使用源码中的真实类名和驼峰属性。数据库字段采用下划线；表中的 Java 类型不能直接当作公开 HTTP 响应。DTO 位于 `quality-digital-coil/src/main/java/com/wisdri/koi2/dc/piece/dto/`。

## 物料跟踪树

### OCPieceTreeNode：一条追溯路径上的出口节点

| 字段 | Java 类型 | 语义、生命周期与约束 |
| --- | --- | --- |
| unitCode | String | 当前节点机组，建树时赋值 |
| cellCode | String | 当前加工单元，决定路线顺序和处理方式，建树时赋值 |
| outMatTrackKey | OCPieceMatTrackKey | 当前出口跟踪联合身份，不是最终卷身份 |
| outMatKey | MatKey | 当前出口物料号联合身份，复用 common/MatKey |
| relations | List<MatCellsBlood> | 当前完整关系；并卷入口焊接顺序、分卷出口切分顺序，无重复；不可增删 |
| lastCells | Map<OCPieceMatTrackKey,OCPieceTreeNode> | 键为当前入口跟踪身份，值为上游出口节点；保持入口业务顺序；无上游的入口不加入，空表示追溯终止 |
| pieceOnlineMatDatas | Map<MatKey,OCPieceOnlineMatData> | 键为当前入口物料号身份；建树时 null，在线阶段整体填充产片节点；不可与 lastCells 键类型混用 |
| pieceMetaData | OCPieceMetaData | 当前路径片号、坐标和累计方向；建树时 null，坐标全部成功后整体赋值 |

结构字段为 final，在线数据和元数据有 setter。节点不生成递归 equals/hashCode/toString，同一上游物料经不同路径创建独立节点，避免可变计算状态互相覆盖。getCellProfile() 按 cellCode 返回已登记加工单元配置。

### OCPieceMatTrackKey：跨加工单元跟踪身份

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| matTrackNo | String | 当前集合语义决定入口或出口物料跟踪号 |
| prodNo | String | 跟踪生产次数，保留前导零，不作数值转换；不是物料重复生产次数 |

不可变 @Value 类型，可作 Map 键。身份要结合加工单元理解，不能仅以此键全局判环。

### MatKey：共用物料号身份

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| matNo | String | 入口或出口物料号，由持有集合指明方向 |
| repeatProdNo | String | 该物料重复生产次数，保留原值及前导零 |

代码实际复用 common/MatKey，没有另建 OCPieceMatKey 或 OCPMatKey。

### OCPieceOnlineMatData：单入口在线实绩

| 字段 | 类型/单位 | 说明 |
| --- | --- | --- |
| timeWindow | ProdTimeWindow | 该入口完整生产区间及扩展查询窗，Asia/Shanghai |
| trHead、trTail | BigDecimal，米 | 卷取机切头、切尾，非负，无记录 0 |
| trSlice | List<BigDecimal>，米 | 卷取机分切量，按设备+组号汇总并按首刀时间排序；分卷长度 n−1，缺补零、多截断；非分卷空 |
| head、tail | BigDecimal，米 | 全部设备切头、切尾，已经包含 trHead/trTail，无记录 0 |
| slice | List<BigDecimal>，米 | 全部设备分切量，同键汇总，缺补零、多保留；非空片分卷跨节点时要求可与出口缝匹配 |
| uncoilerMethod | String | 实际或默认开卷原码；首位 1 上开卷、9 下开卷，准备后非空 |
| coilerMethod | String | 实际或默认卷取原码；首位 1 上卷取、9 下卷取，准备后非空 |
| trimmingLength | BigDecimal，毫米 | 本加工单元在线坐标单侧切边量，左右各切此值，非负，无记录 0 |

不可变 @Value；集合由服务封装为只读。所有剪切保持在线方向，准备阶段不转换坐标、不缩放。

### ProdTimeWindow：共用时间窗口

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| startProdTime | LocalDateTime | 逐行补开始时间后取最早值，上海本地时间 |
| endProdTime | LocalDateTime | 同入口全部关系最晚结束时间，上海本地时间 |
| queryStartTime | LocalDateTime | startProdTime−1h，上海本地时间 |
| queryEndTime | LocalDateTime | endProdTime+1h，上海本地时间 |

源开始时间可缺失，以该行结束前 2h 兜底；结束缺失或开始晚于结束则失败。字段无时区信息，由 PieceSampleReader 明确按 Asia/Shanghai 转为瞬时时间绑定查询。

### OCPieceMetaData：当前成品的路径切片状态

| 字段 | 类型/单位 | 说明 |
| --- | --- | --- |
| pieces | List<PieceRange> | 最终片号对应当前成品坐标，可只覆盖部分成品；保留最终片号递增顺序，局部坐标可反向，片号可稀疏，无重复，空表示无有效片 |
| upDownReverse | boolean | true 当前成品相对最终成品上下反向，false 同向；根初值 false |
| osDsReverse | boolean | true 当前成品操作侧传动侧相对最终成品互换，false 同向；根初值 false |
| osTrimming | BigDecimal，毫米 | 最终映射区域距当前成品操作侧边缘累计距离，非负，根初值 0 |
| dsTrimming | BigDecimal，毫米 | 最终映射区域距当前成品传动侧边缘累计距离，非负，根初值 0；翻侧时交换两侧 |

实际为不可变 @Value。切边是数值 BigDecimal，不是 Boolean；Java 字段为驼峰命名。代码复用 PieceRange，没有 OCPieceRange 类。

### PieceRange：最终片号与当前成品米制区间

| 字段/方法 | 类型 | 说明 |
| --- | --- | --- |
| pieceNo | int | 从 1 起的最终成品片号；上游保留原号，不重排编号 |
| outMatStart | BigDecimal | 当前成品带头起算的起点，米；每片端点从小到大 |
| outMatEnd | BigDecimal | 当前成品带头起算的终点，米，必须大于起点 |
| getPieceLength() | BigDecimal | end−start，米，实时推导，不单独维护可变字段 |

头尾反转后片号序可能对应坐标逆序；不能按列表位置推算局部坐标或把片号当作当前工序重新等分的编号。

## 跨工序跟踪基础数据

### OCPieceBaseData

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| unitCodeToFactory | Map<String,BizDigitalFactory> | 仅本次路径产片机组配置，按机组去重、不可增删；罩式炉和原料不要求配置 |
| parameters | Map<String,List<BizParameter>> | 同样机组范围的数字参数；每列表非空、uniqueKey 排序、键无重复，集合只读 |

本对象不含所有历史清理机组，历史清理由编排另读 configuredFactories 提供。来源实体不回写，但只读集合不意味着实体对象自身深度不可变。

## 跨工序查询结果

### OCPieceQueryData

| 字段 | 类型/单位 | 说明 |
| --- | --- | --- |
| piece | PieceRange | 最终片号及当前成品区间 |
| values | Map<String,BigDecimal> | 配置 unique_key→均值/插值；无有效值为 null，键必须完整 |
| defectGroups | String | JSON 数组，带当前成品位置前缀，空为 []，最多 16384 UTF-8 字节 |
| defectUpDownReverse | boolean | true 缺陷在线上下相对最终成品反向，false 同向 |
| defectOsDsReverse | boolean | true 缺陷在线操作侧传动侧相对最终成品互换，false 同向 |
| defectOsTrimming | BigDecimal，毫米 | 直接沿用当前元数据 osTrimming |
| defectDsTrimming | BigDecimal，毫米 | 直接沿用当前元数据 dsTrimming |

查询返回 `Map<OCPieceTreeNode,List<OCPieceQueryData>>`，仅含成功取值的产片节点，空列表也可能是成功节点。非产片节点不写入结果；失败节点只记日志并跳过，全部失败时抛异常。

## 加工单元配置

OCPieceCellProfile 的 cellCode 为归一大写代码，traceOrder 为严格先后顺序；uncoilerMethod/coilerMethod 是缺失实绩默认值。两默认值齐全才 producesPieces=true，YL001 为 isTraceStart=true。具体路线表见[数据源介绍](多工序数字钢卷切片相关数据源介绍.md)。

## 实现依据

`dto/common/MatKey.java`、`PieceRange.java`、`ProdTimeWindow.java` 及 `dto/overcell/*.java`。这些内部结构没有通过当前控制器直接暴露为树查询响应。
