# 数字钢卷切片计算过程中的数据映射关系

## 背景与两层坐标

跨工序以最终成品切片为基准，把同一最终片号映射到历史加工单元的成品卷，再把该节点成品片映射到本工艺或表检在线卷。两层长度来源、剪切范围不同，不能共用一个在线缩放系数。

| 层级 | 输入→输出 | 长度基准 | 剪切 |
| --- | --- | --- | --- |
| 跨节点 | 当前成品→入口，即上游成品 | 上游目标成品 out_mat_length | 全部设备 head/tail/slice |
| 节点内 | 当前成品→本段在线 | 本段每入口 MAX(head_length)，表检为 MAX(y_position) | 卷取机 trHead/trTail/trSlice |

最终片只生成一次，片号永久保留。上游区间以当前成品带头为原点，米；累计切边为毫米。局部坐标反向或并卷分支导致片号稀疏时，不能重新按上游配置片长切片。

## 长度维度映射

### 共用跨节点公式

设当前片 [s,e]，某入口在当前成品中的贡献区间 [A,B]，上游成品实长 P，恢复完整长度 F，尾端偏移 O：

```text
parentStart = P × (F − (e − A + O)) / F
parentEnd   = P × (F − (s − A + O)) / F
parentPieceNo = currentPieceNo
```

每片端点仍按升序保存，片列表按最终片号递增，可能与局部坐标顺序相反。全部计算使用 BigDecimal，除法采用 DECIMAL128。

### 正常卷

当前成品长 L，全部设备切头 H、切尾 T：

```text
A=0, B=L, F=L+H+T, O=T
```

用 P 而不是本段在线长度计算缩放。开卷不另加纵向反转；一次卷取对应一次头尾反转。

### 分卷

n 个已知出口按切分顺序排列，长度 L[j]，全部设备分切 S[t]。目标下标 i：

```text
F = H + T + sum(L[j]) + sum(S[t])
O = T + sum(L[j] + S[j−1], j>i)
A = 0
B = L[i]
```

对非空片要求全部设备 S 长度恰为 n−1；额外组无法定位成品间缝时直接失败，不静默丢弃实绩。跨节点映射越界或空区间报错；节点内复用单工序算法则有分卷负起点后停止的保护，两者错误处理不同。

例：两个出口长 [40,60]，H=2、T=3、S=[5]，上游 P=220，则 F=110；出口 1 的 [0,10] 映射至上游 [64,84] 米，出口 2 的 [0,10] 映射至 [194,214] 米。片号保持最终卷各自原号，不能用该上游区间重新编号。

### 并卷

每个入口必须能取得上游节点和成品实长 P[i]，即使原料入口不产片，也必须保留其长度以参与比例。

```text
R[i] = P[i] − H[i] − T[i]，每项必须为正
理论起点[i] = L × sum(R[j], j>i) / sum(R)
B[i] = 前一焊接入口的 A；首入口的 B 为 L
F[i] = B[i] − A[i] + H[i] + T[i]
O[i] = T[i]
```

A[i] 由理论起点按当前已覆盖片段对齐：若落在某片内，移到该片尾；若恰为片起点保持原值；若落在未覆盖空隙，保留理论位置。各理论边界独立计算，不累计此前对齐位移。

仅完整落入某入口贡献范围的片传到该分支，跨界片报错；原料入口只占据贡献区间，不再接收元数据。重复上游经不同分支生成独立节点，片集合和方向分别累计。

### 罩式炉与原料

BAF1001 只允许正常关系、一入口一出口一上游，元数据原样传给上游，不读在线实绩、不缩放、不改变方向/切边。YL001 在树中保留以提供实长并结束追溯，不产片、不接收最终片元数据。

### 节点内取值

PieceLengthCalculator.convertMapped 复用[单工序长度公式](../单工序切片/数字钢卷切片计算过程中的数据映射关系.md)，允许稀疏最终片号、局部坐标反序，并检查片间不重叠和成品越界。并卷接缝落在实际片内才对齐，空隙中的接缝保持理论值。

工艺各段独立使用自己的在线长度和卷取机剪切。跨工序表检也独立 convertMapped；没有单工序表检固定首个有效工艺贡献边界的额外约束。覆盖范围按最终片号取集合交集，不按结果条数截列表。

## 表面方向累计

设当前元数据上下反转 U、操作侧传动侧反转 S，lowerCoil 表示下卷取、lowerUncoil 表示下开卷，⊕ 为异或：

```text
上游 U' = U ⊕ lowerCoil ⊕ lowerUncoil
上游 S' = S ⊕ (!lowerCoil) ⊕ lowerUncoil
```

| 开卷/卷取 | 本步上下变化 | 本步操作侧传动侧变化 | 本步头尾变化 |
| --- | --- | --- | --- |
| 上开/上卷取 | false | true | 反转 |
| 下开/上卷取 | true | false | 反转 |
| 上开/下卷取 | true | false | 反转 |
| 下开/下卷取 | false | true | 反转 |

最终成品元数据 U=false、S=false。查询当前节点在线缺陷时只再叠加本节点卷取，不再加开卷：

```text
defect_up_down_reverse = U ⊕ lowerCoil
defect_os_ds_reverse   = S ⊕ (!lowerCoil)
```

方向所属入口优先采用该片表检映射入口；无表检时采用首个有效工艺段入口。跨工序所有产片机组都会计算这两个标志，即使当前机组不读表检或缺陷为空，也不能简单要求两标志均 false。

## 切边量映射

当前元数据两侧累计距离为 os、ds，本单元在线单侧切边量 t，均为毫米。传播到上游遵循代码顺序：

1. 成品→在线：上卷取交换两侧，下卷取不交换，得到 onlineOs、onlineDs。
2. 两侧分别加本单元 t，得到 trimmedOnlineOs、trimmedOnlineDs。
3. 在线→入口：下开卷交换两侧，上开卷不交换，作为上游 osTrimming、dsTrimming。

```text
onlineOs = lowerCoil ? os : ds
onlineDs = lowerCoil ? ds : os
trimmedOnlineOs = onlineOs + t
trimmedOnlineDs = onlineDs + t
parentOs = lowerUncoil ? trimmedOnlineDs : trimmedOnlineOs
parentDs = lowerUncoil ? trimmedOnlineOs : trimmedOnlineDs
```

例如当前 os=2、ds=5、t=3，均为毫米，上开/上卷取时得到上游 os=8、ds=5；下开/上卷取时为 os=5、ds=8。虽然当前根从 0/0 开始且来源单侧切边相同，两侧字段仍独立维护以满足方向语义。

当前节点写入 defect_os_trimming、defect_ds_trimming 时直接取其元数据累计值，不再按本节点卷取方式交换，也不再添加本节点 t；本节点切边是在向其上游传播时加入。

## 缺陷位置与显示边界

defect_groups 前缀为当前工序成品坐标：`x = A + (C−y)×F/C−O`，来自段内 PiecePositionMapping。它不是最终成品位置，也不是片内偏移。每个路径复用原始缺陷索引后分别反算，显示时按米保留三位小数。

缺陷成品 [起点,终点) 对应在线 (小端,大端]；工艺均值在线双闭。前端消费方向和切边的注意事项见[展示缺陷时如何处理切片量](../跨工序界面展示/展示缺陷时如何处理切片量.md)。
