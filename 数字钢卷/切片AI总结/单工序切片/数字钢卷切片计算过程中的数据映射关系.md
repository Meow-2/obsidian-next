# 数字钢卷切片计算过程中的数据映射关系

## 背景与坐标约定

在线坐标从最先开出的带头向带尾递增；成品坐标从卷取后成品带头向带尾递增。卷取使头尾反转；不同工艺设备段的采样时间和在线完整长度可以不同，按长度坐标关联可消除设备位置带来的时间错位。

| 变化 | 上下反转 | 操作侧/传动侧互换 | 头尾反转 |
| --- | --- | --- | --- |
| 上卷取：在线→成品 | 否 | 是 | 是 |
| 下卷取：在线→成品 | 是 | 否 | 是 |
| 上开卷：入口→在线 | 否 | 否 | 否 |
| 下开卷：入口→在线 | 是 | 是 | 否 |

单工序段内纵向映射只涉及成品→在线，单工序不累计切边。开卷用于跨工序成品→入口的方向传播。

## 变量命名与单位

| 变量 | 说明 |
| --- | --- |
| L、p | 目标成品长度、配置片长，米，均为正 |
| x、[s,e] | 相对目标成品带头的位置、片段边界，米 |
| C 或 C[i] | 当前来源表对应入口完整在线长度，米，来自同批采样最大 head_length |
| H、T、S[i] | 卷取机 trHead、trTail、trSlice，米，按在线方向记录 |
| F | 恢复剪切后的完整长度，米，缩放分母 |
| A、B | 某入口在成品坐标的贡献起点、终点，米 |
| O | 从在线尾端恢复至目标贡献段带头的未缩放距离，米 |
| k | C/F，无单位；各来源、各入口独立计算 |

业务 out_mat_sequence_no 从 1 开始且连续；以下 i/j 为排序后的数组下标，从 0 开始，空集合求和为 0。

## 长度维度映射

### 共用公式

对位于入口贡献段 [A,B] 的成品位置 x：

```text
y(x) = C × (F − (x − A + O)) / F
coilStart = y(e)
coilEnd   = y(s)
```

返回在线端点升序。实现合并乘法与减法后才做 DECIMAL128 除法，避免先舍入 k 使精确零端点越界。不能直接用在线长度减未缩放成品距离。

### 正常卷

```text
A = 0
B = L
F = L + H + T
O = T
k = C / F
y(x) = C − (x + T) × k
```

在线切尾对应成品带头，在线切头对应成品带尾。L=100、H=5、T=3、C=110 时，成品 [0,10] 映射为约 [96.759259,106.944444] 米。剪切和成品距离一起参与缩放。

### 并卷

多个入口按焊接顺序保存，成品从头到尾的贡献排列与焊接顺序相反。

```text
R[i] = C[i] − H[i] − T[i]             # 每个入口均须为正
理论起点[i] = L × sum(R[j], j>i) / sum(R)
A[i] = 不小于理论起点的首个已有成品片尾；0 仍为 0
B[i] = 前一个焊接入口的 A；首入口的 B 为 L
F[i] = B[i] − A[i] + H[i] + T[i]
O[i] = T[i]
y(x) = C[i] × (F[i] − (x − A[i] + O[i])) / F[i]
```

所有理论边界独立按原累计保留长度比例计算，不累计前一边界的对齐误差。对齐后零贡献入口跳过；整片不拆分。边界精确相等时保持该边界，以交叉乘法比较分式，避免循环小数误差导致多移一片。

例如 L=100、p=10，两入口无剪切、C=[30,70]：成品 [0,70] 属于入口 2，[70,100] 属于入口 1。若理论接缝为 66.6… 米则向 70 米片尾对齐，再以实际贡献长度重算各入口缩放。

工艺段在线长度不同可造成并卷归属不同；每段独立计算。单工序表检是特例：固定首个有效工艺段的入口贡献边界，仅用表检独立在线长度换算，不重新按缺陷位置分配并卷贡献。

### 分卷

n 个出口沿在线切分顺序排列，长度 L[j]；S[t] 对应出口 t 和 t+1 之间的分切量，共 n−1 项。目标下标 i：

```text
A = 0
B = L[i]
F = sum(L[j], j=0..n−1) + H + T + sum(S[t], t=0..n−2)
O[i] = T + sum(L[j] + S[j−1], j=i+1..n−1)
k = C/F
y(x) = C × (F − (x + O[i])) / F
```

偏移只累计目标之后的出口及其前方分切，全部出口和全部分切参与同一个缩放分母；不能只用目标卷长度计算 k。单出口分卷退化为正常卷。

例：出口 [40,60]、H=2、T=3、S=[5]、C=110，则 F=110。出口 1 的 O=68，其 [0,10] 对应在线 [32,42]；出口 2 的 O=3，其 [0,10] 对应 [97,107]。两卷之间保留分切空隙。

当前算法在分卷映射起点小于 0 时停止，不把负起点裁为 0，不改变原片尾；只返回计划中的连续完整前缀。由于完整恢复长度包含全部出口，合法完整数据通常能覆盖全部片；此分支是边界保护，不是一般性的“在线长度小就按比例丢片”。

## 采样与缺陷的区间边界

| 用途 | 成品/在线条件 | 共享边界 |
| --- | --- | --- |
| 工艺均值 | 在线 [coilStart,coilEnd] 双闭 | 样本可进入相邻两片 |
| 缺陷归属 | 成品 [s,e)，在线 (coilStart,coilEnd] | 只进入成品后一片，终点 e 排除 |
| 时间定位 | 整个有效贡献区间，在线双闭 | 返回命中真实采样的 MIN/MAX ts |

缺陷纵向反算复用本片保留的 PiecePositionMapping：

```text
x = A + (C − y) × F / C − O
```

在线大端点直接返回原成品起点，小端点直接返回原成品终点。位置前缀按米 HALF_UP 保留三位小数，仅影响展示；归属判断使用未舍入坐标。

## 切边量映射

qm_dc_trimming_log 的 trimming_length 是单侧切边量，单位毫米。当前单工序切片不读取或输出累计切边量；它用于跨工序追溯。长度与剪切的米制数值不能直接与切边毫米值混算。
