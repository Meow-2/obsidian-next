# 数字钢卷切片相关数据源介绍

## 数据源与职责

PostgreSQL 的 master 数据源读取配置、物料关系和生产实绩；TDengine 的 slave1 读取在线工艺与表检。结果建表、删除、保存通过 quality-ts HTTP 接口完成。本页列出切片实际消费字段，类型为 Java 只读投影或语义类型，不把实体投影当作源表完整 DDL。

PostgreSQL 实体中 deleted=0 有效、1 逻辑删除，由 MyBatis-Plus 自动排除已删除记录。

## Postgres quality 数据库

### qm_biz_digital_factory 数字工厂

#### 作用

按 code=归一化大写机组代码定位，必须恰一条有效配置。

| 字段 | 类型/单位 | 使用与约束 |
| --- | --- | --- |
| id | Long | 配置表主键 |
| code | String | 机组代码，同一机组仅一条有效配置 |
| piece_length | BigDecimal，米 | 正数，控制完整成品分片，末片可短于配置值 |
| piece_ts_database | String | 切片结果库，必填，不限于来源工艺库 |
| piece_ts_table | String | 单工序结果表，必填，以配置为准，不拼接机组名 |
| oc_piece_ts_table | String | 跨工序结果表；单工序产出不要求此字段 |
| deleted | Integer | 0 有效、1 删除 |

### qm_biz_parameter 参数资源表

#### 作用

按 unit_code 查询数字工艺参数，条件是 ts_database='digital_coil'、value_type IN ('float','short','int','long','double','byte')，且表名包含 process 或 ironloss；只在表名条件内部作 OR。按 unique_key 排序。

| 字段 | 类型 | 使用与约束 |
| --- | --- | --- |
| id、deleted | Long、Integer | 主键与逻辑删除 |
| unit_code | String | 归属机组 |
| name | String | 参数名称，必填 |
| unique_key | String | 来源参数列及结果动态列；必填、机组内忽略大小写不重复，不得覆盖固定列 |
| value_type | String | 来源类型白名单；bool、boolean、string 等不参与均值 |
| ts_database | String | 来源库，仅 digital_coil |
| ts_table | String | 来源表；按实际配置分组，不推导表名 |

来源数值类型不决定结果列类型，结果统一 DOUBLE。动态库表和列名需通过标识符正则检查；实际写入标识符最长 64 个字符。

### qm_mat_cells_blood 机组内物料关系表

#### 作用

先按 unit_code + cell_code + out_mat_no + out_mat_repeat_prod_no 定位；分卷补查相同机组、加工单元、入口号及入口重复次数的全部已知出口。

| 字段 | 类型/单位 | 使用与约束 |
| --- | --- | --- |
| id、deleted | Long、Integer | 关系主键与逻辑删除 |
| unit_code、cell_code | String | 本次加工范围，必须匹配请求 |
| in_mat_no、in_mat_repeat_prod_no | String | 入口物料联合身份，次数保留字符串 |
| out_mat_no、out_mat_repeat_prod_no | String | 出口物料联合身份 |
| in_mat_track_no、in_mat_prod_no | String | 入口跟踪联合身份，单工序不用于跨单元查询 |
| out_mat_track_no、out_mat_prod_no | String | 出口跟踪联合身份，区别于物料号和重复次数 |
| mat_type | String | 0 正常、1 并卷、2 分卷，其他拒绝 |
| out_mat_sequence_no | String→正整数 | 并卷入口焊接顺序/分卷出口切分顺序；从 1 连续，无重复 |
| out_mat_length | BigDecimal，米 | 出口实长，正数；同一并卷出口各行必须一致 |
| start_prod_time | LocalDateTime | 上海本地生产开始时间，可空，计算时以该行结束时间减 2h 兜底 |
| end_prod_time | LocalDateTime | 上海本地生产结束时间，计算必需；不得早于有效开始时间 |

正常卷恰一行；并卷多入口一出口；分卷一入口多出口，允许当前仅已到达一个出口。不允许并卷与分卷混合关系。读入后不修改源实体。

### qm_dc_shear_log 剪切实绩表

#### 作用

按机组、加工单元和入口物料联合身份读取 tr 前缀设备。无时间窗过滤。

| 字段 | 类型/单位 | 使用与约束 |
| --- | --- | --- |
| unit_code、cell_code、in_mat_no、in_mat_repeat_prod_no | String | 限定剪切归属，不用跟踪次数替代重复次数 |
| shear_type | String | 至少三位，第三位 1 切头、5 分切、9 切尾 |
| shear_length | BigDecimal，米 | 每刀长度，非负；无需 mm→m 转换，不乘 cut_no 或刀数 |
| shear_device_code | String | 单工序仅 tr 前缀卷取机，按原始前缀匹配 |
| shear_no | Integer | 分卷分切组号，正数，单工序按组号合并各刀 |
| shear_time | LocalDateTime | 分切顺序依据，按上海生产时间解释；分卷分切时必填 |
| cut_no | Integer | 组内刀次，当前长度汇总不使用 |
| id、deleted | Long、Integer | 定位异常记录及逻辑删除 |

### qm_dc_coiler_log 开卷卷取实绩表

仅 CP1/FCL1 单工序读取。按 cell_code + 入口号 + 入口重复次数定位，取 create_time 降序、NULLS LAST、id 降序首条。

| 字段 | 类型 | 使用与约束 |
| --- | --- | --- |
| cell_code、in_mat_no、in_mat_repeat_prod_no | String | 实绩归属 |
| coiler_method | String | 首位 1 上卷取、9 下卷取；其余位保留但不参与表面方向计算 |
| uncoiler_method | String | 单工序不消费，跨工序使用 |
| create_time | LocalDateTime | 来源生产时区创建时间，用于选最新，不是采样时间 |
| id、deleted | Long、Integer | 最新记录稳定排序与逻辑删除 |

CP1/FCL1 无最新记录或编码非法则失败，不能以加工单元默认值兜底。非表检机组不读取此表，单工序两个缺陷方向标志均为 false。

### qm_dc_trimming_log 切边实绩表

单工序流程不读取该表。跨工序使用 trimming_length 的十进制文本，单位毫米，表示在线两侧各切去的宽度；不能把它当作米制纵向剪切。详见[跨工序数据源](../跨工序切片/多工序数字钢卷切片相关数据源介绍.md)。

## TDengine digital_coil 数据库

### 工艺参数表

#### 作用与读取口径

库表由参数配置指定，常见命名如 `<unit>_process_<segment>`、`fcl1_ironloss_iron_loss`，示例不替代实际配置。

```sql
-- 语义示例：生产时间按上海时区转成瞬时时间绑定；MAX 在本批结果中计算。
SELECT head_length, <本表配置的数字参数列>
FROM digital_coil.<配置表>
WHERE coil_no = :inMatNo
  AND repeat_prod_no = :repeatAsInteger
  AND cell_code = :cellCode
  AND ts >= :queryStartTime
  AND ts <= :queryEndTime;
```

repeat_prod_no 查询前由入口重复次数字符串转非负 int；非法整数、溢出或负数会失败。关系与结果身份仍保留原始字符串。

| 字段 | 语义 |
| --- | --- |
| ts | 原始采样时间，时间定位额外读取，需为 Timestamp |
| head_length | 到当前工艺段在线带头距离，米；NULL 行排除；每入口最大值必须为正才算有效段 |
| coil_no、repeat_prod_no、cell_code | 入口号、数值重复次数、加工单元过滤条件 |
| unique_key 对应列 | Number 或 NULL；按十进制文本转换 BigDecimal，不把字符串隐式转数值 |

查询窗为入口合并生产区间前后各扩展 1h。每表每入口读一次必要采样，同批计算在线长度和均值，不按切片逐条访问数据库。缺长度降级和插值详见[接口流程](数字钢卷切片接口.md)。

### qm_defect_surface_check_monthly 表面缺陷月超级表

实际读取的是 monthly 表，并非旧设计中的 qm_defect_surface_check。只有 CP1/FCL1 使用。

| 字段 | 类型/单位 | 使用与约束 |
| --- | --- | --- |
| unit_code | String | 机组过滤 |
| end_month | String，YYYY_MM | 原始生产结束年月，跨月卷仍属结束月份 |
| in_mat_no | String | 入口物料号，保留大小写；是普通列，不是按卷子表标签 |
| ts | Timestamp | 原始缺陷时间，保留小数秒；与 source_id 联合定位 |
| source_id | 来源 BIGINT，投影 String | 与 ts 组成子表内复合身份，不可只按 ts 定位 |
| y_position | BigDecimal，米 | 在线纵向位置，非负且非空；入口最大值用作表检长度 |
| up_down | Integer | 0 上表面、1 下表面；单工序读取时校验 |

查询按 unit_code、end_month、in_mat_no、扩展 ts 窗口过滤，无入口重复次数或 cell_code 过滤列。重复加工区分依赖生产时间窗，因此来源时间质量直接影响隔离效果。
