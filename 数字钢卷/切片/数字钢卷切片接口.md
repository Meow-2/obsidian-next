# 数字钢卷切片接口

## 接口路径

POST /api/quality/piece/output

## 入参

| 参数                 | 类型     | 必填  | 说明          |
| ------------------ | ------ | --- | ----------- |
| unitCode           | String | 是   | 机组代码        |
| outMatNo           | String | 是   | 出口物料号       |
| outMatRepeatProdNo | String | 是   | 出口物料重复生产次数号 |
| cellCode           | String | 是   | 加工单元代码      |

## 数字钢卷切片流程

### 基础数据初始化

1. qm_biz_digital_factory 表查询机组对应的数字钢卷切片存储的时序数据库、表名和精度
2. qm_biz_parameter 表查询机组对应的数字钢卷工艺参数的名字、类型、唯一键和存储的时序表和时序库
3. qm_mat_cells_blood 查询加工单元对应的入口出口物料流转情况

### qm_mat_cells_blood 数据补全

qm_mat_cells_blood 查询出来的行的需要记录其各个入口物料的切头、切尾、左切边、右切边、开卷、卷取结果

1. 根据入口物料相关字段在 qm_dc_coiler_log 中取对应开卷卷取方式。
   数据转换：qm_dc_coiler_log 中的开卷卷取方式的第一位为 1 代表上，第一位为 9 代表下，其中 9 需要转换为 0，适配 qm_mat_cells_blood 字段的语义
2. 根据入口物料相关字段在 qm_dc_trimming_log 中取对应的切边量。
   数据转换：qm_dc_triming_log 中只有切边量一列，这意味着左切边量和右切边量值一致，在对应到 qm_mat_cells_blood 的左切边量、右切边量时，要根据开卷方式进左右调换，见原料卷坐标到在线卷坐标变化中的左右变换
