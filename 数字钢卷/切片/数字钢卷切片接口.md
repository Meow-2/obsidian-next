# 数字钢卷切片接口

## 接口路径

POST /api/quality/piece/output

## 入参

| 参数                 | 类型     | 必填  | 说明          |
| ------------------ | ------ | --- | ----------- |
| unitCode           | String | 是   | 机组代码        |
| outMatNo           | String | 是   | 出口物料号       |
| outMatRepeatProdNo | String | 是   | 出口物料重复生产次数号 |
| cellCode           | String | 是   | 加工单元代码      |

## 数字钢卷切片流程

### 数据初始化

1. 查询机组对应的 qm_biz_digital_factory 数字钢卷切片存储的时序数据库、表名和精度
2. 查询机组对应的 qm_biz_parameter 参数的名字、类型、唯一键和存储的时序表和时序库
