### qm_mat_cells_blood 机组内物料关系表

#### 作用一：描述每个加工单元的入口出口物料流转情况

查询关键字：out_mat_no + out_mat_repeat_prod_no + cell_code

查询结果关键字段：in_mat_no + in_mat_repeat_prod_no + cell_code + mat_type + out_mat_sequence_no

说明：当 mat_type = 0 时，加工单元正常产出，查询结果只有一条，入口物料和出口物料是 1 对 1 的关系；

当 mat_type = 1 时，加工单元并卷产出，查询结果有

#### 作用二：描述每个加工单元的入口出口物料分卷/并卷/正常情况

查询关键字：out_mat_no + out_mat_repeat_prod_no + cell_code

查询结果关键字段：in_mat_no + in_mat_repeat_prod_no + cell_code + mat_type + out_mat_sequence_no

并卷的情况下，查询结果尾多条

#### 作用二：记录切片过程中计算的各个入口物料的切头、切尾、左切边、右切边、开卷、卷取结果

查询关键字段：out_mat_no + out_mat_repeat_prod_no + cell_code

查询结果关键字段：in_mat_no + in_mat_repeat_prod_no + cell_code + head_cut_length + tail_cut_length + left_trim_width + right_trim_width + por_type + tr_type

切头、切尾、左切边、右切边、开卷、卷取结果：在生成切片的过程中写入表内
