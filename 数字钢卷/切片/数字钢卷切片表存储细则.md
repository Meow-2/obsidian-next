# 数字钢卷切片表存储细则

使用 Mybatis Plus 框架来写入相关数据库表，Mybatis Plus 功能不能满足的，使用 Mybatis 在 XML 中写 sql 的形式来完成

每个机组有一张对应的数字钢卷切片表，存储在 TDengine 时序库中，具体的数据库名和表名在 qm_biz_digital_factory 表中配置

#### 表结构

该表的工艺参数字段列获取自 cube-api 的/aygg_tracking 跟踪树，每次进行切片计算前，要先调用该接口获取最新的工艺参数字段列，并更新数字钢卷切片表结构（只新增列，不删除列）

```sql
CREATE TABLE qm_dc_<unit_code_lowercase>_pieces (
    id                      BIGINT PRIMARY KEY,
    create_time             TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    create_user             BIGINT,
    create_org              BIGINT,
    update_time             TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    update_user             BIGINT,
    deleted                 INTEGER DEFAULT 0,
    unit_code               VARCHAR(50),
    out_mat_no              VARCHAR(50),
    out_mat_repeat_prod_no  VARCHAR(50),
    cell_code               VARCHAR(50),
    piece_length            NUMERIC(12, 6),
    piece_no                INTEGER,
    defect_groups           VARCHAR(100)[] DEFAULT '{}'::VARCHAR(100)[]
);

COMMENT ON TABLE qm_dc_<unit_code_lowercase>_pieces IS '机组出口物料切片表';

COMMENT ON COLUMN qm_dc_<unit_code_lowercase>_pieces.id IS '切片记录主键，由应用生成';
COMMENT ON COLUMN qm_dc_<unit_code_lowercase>_pieces.create_time IS '创建时间，不带时区';
COMMENT ON COLUMN qm_dc_<unit_code_lowercase>_pieces.create_user IS '创建用户ID';
COMMENT ON COLUMN qm_dc_<unit_code_lowercase>_pieces.create_org IS '创建组织ID';
COMMENT ON COLUMN qm_dc_<unit_code_lowercase>_pieces.update_time IS '最后更新时间，不带时区，由应用在更新时维护';
COMMENT ON COLUMN qm_dc_<unit_code_lowercase>_pieces.update_user IS '最后更新用户ID';
COMMENT ON COLUMN qm_dc_<unit_code_lowercase>_pieces.deleted IS '逻辑删除标记：0未删除，1已删除';
COMMENT ON COLUMN qm_dc_<unit_code_lowercase>_pieces.unit_code IS '机组代码';
COMMENT ON COLUMN qm_dc_<unit_code_lowercase>_pieces.out_mat_no IS '出口物料号';
COMMENT ON COLUMN qm_dc_<unit_code_lowercase>_pieces.out_mat_repeat_prod_no IS '出口物料重复生产次数号';
COMMENT ON COLUMN qm_dc_<unit_code_lowercase>_pieces.cell_code IS '加工单元代码';
COMMENT ON COLUMN qm_dc_<unit_code_lowercase>_pieces.piece_length IS '切片长度，单位米，保留6位小数';
COMMENT ON COLUMN qm_dc_<unit_code_lowercase>_pieces.piece_no IS '切片序号，从1开始';
COMMENT ON COLUMN qm_dc_<unit_code_lowercase>_pieces.defect_groups IS '表检仪缺陷主键，<unit_code_uppercase>@@<in_mat_no>@@<ts>@@<source_id>';
```
