# 数字钢卷切片表存储细则

使用 Mybatis Plus 框架来写入相关数据库表，Mybatis Plus 功能不能满足的，使用 Mybatis 在 XML 中写 sql 的形式来完成

每个机组有一张对应的数字钢卷切片表，存储在 TDengine 时序库中，具体的数据库名和表名在 qm_biz_digital_factory 表中配置

#### 表结构示例

该表的工艺参数字段列需要从 qm_biz_parameter 中获取，每次进行切片计算前，要先调用该接口获取最新的工艺参数字段，并更新数字钢卷切片表结构（只新增列，不删除列）

```sql
CREATE TABLE IF NOT EXISTS `<unit_code_lowercase>_piece_output` (
    `ts`                     TIMESTAMP,     -- 切片记录时间，精度由数据库配置决定
    `unit_code`              VARCHAR(50),   -- 机组代码
    `out_mat_no`             VARCHAR(50),   -- 出口物料号
    `out_mat_repeat_prod_no` VARCHAR(50),   -- 出口物料重复生产次数号
    `cell_code`              VARCHAR(50),   -- 加工单元代码
    `piece_length`           DOUBLE,        -- 切片长度，单位：米
    `piece_no`               INT,           -- 切片序号，从1开始
    `defect_groups`          VARCHAR(4096)  -- 缺陷组标识的JSON数组文本，无缺陷时写入 []
) COMMENT '机组出口物料切片表';
```
