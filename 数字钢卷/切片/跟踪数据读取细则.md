### qm_biz_digital_factory 数字工厂

查询关键字段：code

查询结果关键字段：piece_length + piece_ts_database + piece_ts_table

说明：查询结果只有一条

1. code 字段为 unit_code
2. piece_ts_database 、piece_ts_table 为 TDengine 时序库中的表和表名，数字钢卷切片存储在时序库中，ts 写 create_time

### qm_mat_cells_blood 机组内物料关系表

#### 作用一：描述每个加工单元的入口出口物料流转情况

查询关键字段：out_mat_no + out_mat_repeat_prod_no + cell_code

查询结果关键字段：in_mat_no + in_mat_repeat_prod_no + cell_code + mat_type + out_mat_sequence_no

说明：

1. 当 mat_type = 0 时，加工单元正常产出，查询结果只有一条，入口物料和出口物料是一对一的关系；
2. 当 mat_type = 1 时，加工单元并卷产出，查询结果有多条入口物料，入口物料和出口物料是多对一的关系，out_mat_sequence_no 标识其入口物料的拼接顺序
3. 当 mat_type = 2 时，加工单元分卷产出，查询结果只有一条，入口物料和出口物料是一对多的关系。此时还需要用 in_mat_no + in_mat_repeat_prod_no + cell_code 去查询，才能该次流转的完整物料情况，即入口物料对应的所有出口物料

#### 作用二：记录切片过程中计算的各个入口物料的切头、切尾、左切边、右切边、开卷、卷取结果

查询关键字段：in_mat_no + in_mat_repeat_prod_no + cell_code + out_mat_no + out_mat_repeat_prod_no

查询结果关键字段：head_cut_length + tail_cut_length + left_trim_width + right_trim_width + por_type + tr_type

说明：查询结果只有一条，每个加工单元的每个入口物料到每个出口物料的产出关系，都有其对应的切头、切尾、左切边、右切边、开卷、卷取结果，这些字段在表里都是空的，是数字钢卷切片的过程中会根据计算结果写入这些字段

#### 表结构
