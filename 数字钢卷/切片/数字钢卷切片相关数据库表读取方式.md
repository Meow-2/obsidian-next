# 数字钢卷切片相关数据库表读取方式

使用 Mybatis Plus 框架的 **LambdaQueryWrapper** 来读取相关数据库表，Mybatis Plus 功能不能满足的，使用 Mybatis 写 XML 的形式来完成

## 数据库表

### Postgres quality 数据库

qm_mat_cells_blood 机组内物料关系表

qm_dc_shear_log 剪切实绩表

qm_dc_coiler_log 开卷卷取实绩表

qm_dc_trimming_log 切边实绩表

### TDengine digital_coil 数据库

机组的工艺参数是分段分表存储的，每个段一部分

`<unit_code_lowercase>_<process>_<segement_code>`
