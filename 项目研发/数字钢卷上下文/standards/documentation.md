# 文档规范

来源：用户约定，2026-09-16，已确认。

- **尽可能精简，不以篇幅或章节完整为目标。** 一条规则只维护一处，其他位置链接引用。
- 面向 AI：README 集中说明“何时读、读什么、怎么做”；各文档只保留事实、必要指令和边界，不重复阅读说明。
- 删除工具机制介绍、对话历史和操作教程；不为占位内容新增文件。模板只保留必填信息。
- 已确认事实注明来源；代码结论注明仓库、提交与位置。区分业务预期、当前实现和推断，未知项标记待确认。
- 长期文档记录生效状态，变更目录保留目标、方案与验证历史。
- 根目录仅在 project-map.md 开头定义，变量用英文大写；内部链接用相对路径，文件用 UTF-8 Markdown。不得改成环境配置或 JSON 方案。
- 修改后检查事实、状态、链接及重复内容；不保存凭据或敏感生产数据。
